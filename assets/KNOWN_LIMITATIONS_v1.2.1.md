## C 报告
1. v1.2.0 及更早生成的报告没有评价快照，升级后如实显示“无快照”；需重新诊断并生成报告。
2. 报告 PDF 在 Windows 上使用系统微软雅黑/黑体嵌入；若系统缺少这些字体，退回 Adobe CID 字体（不嵌入），页脚注明所用字体。
3. 报告地图为离线坐标散点（无瓦片底图）。界面地图与报告地图的点位颜色均为修复前点位的 GB 15618 筛选值倍数（按点位 pH，农用地类型取修复前门禁登记值），只覆盖八项重金属；有机污染物与 GB 36600 生态口径不在地图着色中体现，法规结论以“法规门禁”章节为准。修复后批次无坐标时不在地图显示。
4. 场地列表“点位记录(全部阶段)”与“超标”列为全部导入记录的合计，非分阶段法规结论；分阶段样品数见场地详情与报告。

## D 软件与部署
1. Windows 验收在 GitHub Actions 虚拟机（管理员账户）上执行；标准账户测试为独立作业，以计划任务身份运行并为测试账户授予“作为批处理作业登录”权限，**不等同**于真人在甲方 Windows 10/11 上交互登录测试。在该作业中：通过 `Start-Process -Credential` 从运行器会话直接启动安装程序失败（退出码 1、未生成日志，判断为跨会话凭据启动限制，非安装程序缺陷）；以标准账户计划任务方式运行时，安装至 `%LOCALAPPDATA%\Programs\SRS` 成功（退出码 0），程序以该账户运行、数据库位于该账户 `%APPDATA%`，验收脚本 portable 阶段（健康、版本 1.2.1、模型加载、空库首启、导入、评价）7/7 通过。
2. 安装包未做代码签名，可能出现 SmartScreen 提示。
3. 升级前请手动备份 `%APPDATA%\SRS`（见 `MIGRATION_ROLLBACK_v1.2.1.md`）。
4. 源码仓库公开可见；`data/raw` 中含甲方原始工作簿（历史遗留），是否从公开历史中移除需所有者决定（本版未改写 Git 历史）。
