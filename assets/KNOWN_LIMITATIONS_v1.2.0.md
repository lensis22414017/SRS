# SRS v1.2.0 已知限制

本版为**年度验收候选版（预发布）**。以下限制已在软件界面、手册与本文件中如实标注。

## A 科学方法（不构成科学验证）
1. 课题二按冻结基线 **M-REC-2025** 执行；方法文件中的笔误与未定义事项 M-01…M-10 采用登记值，待陈亮、宋伟杰老师确认（见 `DEFERRED_REGISTER_v1.2.0.csv`）。
2. 表2.14 熵权不能由所提供的权重计算表复现（该表权重和 1.0108，含笔误），本版不重算权重，直接使用表2.18 发布值。
3. 表2.18 生产指标层权重和为 0.9643（26 项），本版**不归一**；表2.19/2.20/2.21 权重和分别为 1.0001、1.0058、1.0063，原样使用。
4. 不做未登记换算：有机质≠有机碳，全氮≠水解性氮，总铬≠六价铬。缺对应指标时按缺测处理。
5. 课题一 KOS 沿用 v1.1（110 维随机森林 p3_alpha，未重训）；与课题组方法粒度的对齐仍在问题清单中（Q-01）。
6. 课题三 SSUI 为**得分录入模式**：D1–D25 原始值→得分的分级规则未提供；SSUI>1 不截断，标注“超出 0–1 范围”。支持阈值 0.6 为暂定（Q-16）。

## B 数据
1. 尚无任何实测**修复后**数据；修复后结论只在合成演示数据上演示过，真实修复后验证未开始。
2. 子课题个旧测试表（81 点位）来源未核实：六六六/滴滴涕/苯并[a]芘与全氮取值大量与权重计算表相同，光温潜力为常数 3310。只用于说明软件能力。
3. 演示数据为合成数据（种子 20261009），不由任何甲方数据拟合；不代表任何真实场地。

## C 法规阈值
1. 阈值来自生态环境部官网 PDF 的 GB 36600-2018 表1/表2 与 GB 15618-2018 表1–3，逐行人工转录并与知识库独立比对；未包含地方标准。
2. GB 36600 中无标准值的物质（如荧蒽、芘、DDT 类总量、六六六总量）不再给替代阈值，该物质对门禁“无阈值”，在结论中列为证据缺口。

## D 软件与部署
1. Windows 验收在 GitHub Actions 托管 runner（Windows Server 2025，管理员账户）上执行；标准（非管理员）账户为尽力测试，结果见验收证据。未在甲方实际办公电脑上测试。
2. 安装包未做代码签名，首次运行可能出现 SmartScreen 提示。
3. 升级不自动备份数据库；升级前请按《迁移与回退说明》手动备份 `%APPDATA%\SRS`。
4. 截图来自无头 Chromium 访问已安装程序的页面，窗口外观（标题栏、托盘）不在截图内。
5. 源码仓库为公开可见，仓库 `data/raw` 中含甲方原始工作簿（历史遗留，本版未改变仓库可见性，需所有者决定处理方式）。
