# SRS v1.2.1 迁移与回退说明

## 升级（v1.2.0 / v1.1.0 → v1.2.1）
1. 关闭 SRS；复制 `%APPDATA%\SRS` 整个目录作为备份（便携版复制 `SRS\SRS_data`）。
2. 运行 `SRS-Setup-1.2.1-Windows-x64.exe` 覆盖安装（安装目录不变）。
3. 首次启动自动执行（幂等）：建表/加列；`repair_v121_unit_artifacts`（迁移 0009）把误存为“VI/III”等形态标记的检测单位改为因子默认质量浓度单位；阈值库补 GB 15618 水田口径行；不删除任何业务数据或已生成报告。
4. 对已有场地重新运行“障碍因子分析”和“生成报告”，以得到正式/探索性分层和评价快照。v1.2.0 的诊断记录没有 official_ranking_status，报告中会提示“旧版本记录”。

## 回退（v1.2.1 → v1.2.0）
1. 卸载 v1.2.1（不删除用户数据）。
2. 用升级前备份的 `%APPDATA%\SRS` 覆盖当前目录（单位修复不可逆，必须用备份回退）。
3. 安装 v1.2.0-rc.1 的安装包。

## 已验证
- GitHub Actions Windows：v1.1.0 → v1.2.1 与 v1.2.0 → v1.2.1 两条升级路径（见 Windows 验收证据 `acceptance_upgrade*.json`）。
