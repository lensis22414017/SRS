# SRS v1.2.0 发布说明（年度验收候选版，预发布）

污染场地土壤生态-生产功能重构监管系统（SRS）
委托单位：生态环境部土壤与农业农村生态环境监管技术中心 · 承担单位：浙江大学环境与资源学院

> 本版为**年度验收候选版**，以 GitHub 预发布（pre-release）形式发布，不是正式稳定版。科学方法确认与真实修复后数据验证尚未完成（见“三项结论”）。

## 主要变更
**课题二（功能重构可行性）**
- 新增“重构指标导入（课题二）”：模板 RECON-PRE-v1.2（28 项指标，数值与类别分列）→ 上传逐格校验（不入库）→ 确认入库（事务）→ 计算 → 导出；内容 SHA-256 防重复导入。
- 计算改为冻结方法 **M-REC-2025**（方法文件表2.18–2.23、§2.3.3）：表2.18 权重原值不归一；缺测按表2.19/2.21 准则层；内梅罗只用于缺测路径类别分；7 个类别指标按表2.22 赋分；删除无依据默认分。
- 子课题个旧测试表由 v1.1 的 19/28 项可用提升为生产轨道 28/28 项可赋分（清洗 18 个数值文本单元格）。
- 方法笔误与未定义事项 M-01…M-10 显式登记，结果标注方法状态。

**法规阈值**
- GB 36600-2018 表1（45 项）+ 表2（40 项）、GB 15618-2018 表1–3 由生态环境部官网 PDF 逐行转录；12 项 VOC 与知识库 24/24 条一致。
- 移除 24 行非标准阈值（多氯联苯旧值 0.2/2.0、DDT 类、六六六总量、族群匹配替代值）；GB 15618 铜列更正；升级时自动更正旧库。

**课题三与利用结论**
- SSUI 方法不变（得分录入模式）；利用方向结论门禁数据纳入课题二批次点位。
- 五类结论（均支持 / 支持生产 / 支持生态 / 均不支持 / 证据不足）在 5 个合成场地上逐一演示，与独立期望值一致。

**软件**
- 修复文件管理页 403（缺少 `file:read` 权限种子）。
- 版本号由 `VERSION` 单一来源注入（含前端侧栏与系统信息页，原为 v1.0.1）。
- 新增便携版（数据写在 exe 同级 `SRS_data`）。
- 全流程追溯引导新增课题二模板。
- 移除前端中未引用的含场地信息截图。
