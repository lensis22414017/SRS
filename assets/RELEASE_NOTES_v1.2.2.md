# SRS v1.2.2-rc.1 发布说明（收尾候选版 / 预发布）

**状态：收尾候选版（prerelease），不是最终验收版。** 本版执行 2026-10-10《Focused Completion Taskbook》T01–T06。被测提交 `68a52751e8dfa6f6c48b5c20dd8b69b53b54e3b2`（分支 `fix/v1.2.2-closeout`，基于 v1.2.1-rc.1 / e69116c）。v1.2.1-rc.1（e69116c）与 v1.2.0-rc.1（e5a3728）标签保持不变。三个子课题方法互相独立；本版未新增或修改任何阈值、权重、等级区间，也未等待 Q01–Q18 签字。

## 主要变更
| 任务 | 内容 |
|---|---|
| T01 SSUI 定义域 | 原值不在方法文件等级定义域 [0, 1.0] 内时：保留原值、权重与方法版本，**不分级、可行性不判定、不作功能支持**；域内结果标注“暂定演示分级”。界面、JSON、Excel（SSUI 表新增“状态/状态说明”列）、PDF、DOCX 与利用结论同一口径。升级后的 v1.2.1 旧记录（旧版对 SSUI>1 也写 status=ok 并记为“高度可持续”）在读取时按原值重新判定，原等级仅作审计留存。演示包 A–E 课题三得分改为独立随机流生成、全部在域内，五个结论分支不变；v1.2.1 旧得分保留为回归夹具 |
| T02 分析物标识 | 单体按名称与 CAS 号绑定 GB 36600 自身记录（如 DEHP 117-81-7：第一类 42 / 第二类 121 mg/kg；DnOP 117-84-0：390 / 2812 mg/kg）；“邻苯二甲酸酯总量”等族总量无官方总量值即不判定；未登记单体（如邻苯二甲酸二甲酯）转人工复核。取消族→代表物映射（PAEs→DEHP、二甲苯→邻-二甲苯、氯酚→2-氯酚）与族名/子串关键词匹配。同位素标记物/替代物（氯仿-d、萘-d8 等）不按母体物质判定；单个 DDT 异构体、PCB 同系物不与总量限值比较；补充同 CAS 同物异名（三氯甲烷=氯仿、全氯乙烯=四氯乙烯等）。v1.2.1 曾把一个原始场地数据表中的“氯仿-d”按氯仿限值判为正式障碍，已更正（细节只在私有包） |
| T03 用途 | 修复后利用结论要求明确用途：未选择 → “需人工选择用途”（只给假设性保守筛查）；“非建设用地生态用途” → “法规适用性待确认”；与用途无关的超管制值否决保留。评价快照 Excel 新增“利用结论与用途”表；安装程序上验证了无效取值（422）、未选择、非建设用地生态用途与明确选择，并截取界面图 29–31 |
| T04 场地 H | 合成场地 H：企业用户导入 → 课题一 → 方案推荐（候选比选）→ 方案审批阶段记录选定方案 → 五阶段模拟材料上传、模拟审核员审核/退回/再提交 → 角色检查 → 附件下载指纹核对 → 追溯报告“阶段→证据追溯”表 → 安装版重启后保持 |
| T04 产品缺陷修复 | 企业用户导入新建的场地此前不归属任何组织（导入者看不到、访问 403）；五阶段接口接受请求体自报 operator_id；退回无需原因；SSUI 页面域外结果不显示原值、批次表等级列判断字段错误；报告 SSUI 图阈值标注压在柱上 |
| T06 | 客户汇报四章版（课题背景 → 系统架构 → 主要功能 → 课题成果与应用价值；主要功能按数据管理/决策管理/全流程追溯/系统管理）以 01_SRS系统汇报.pptx 为母版修订，截图取自本版 Windows 实装运行 |

## 升级
升级前请备份 `%APPDATA%\SRS`。本版无数据库结构迁移；旧版入库的域外 SSUI 读取时不再分级；含有机污染物的场地请重新运行障碍因子分析并重新生成报告。详见 `MIGRATION_ROLLBACK_v1.2.2.md`。

## 已知限制（摘要）
课题二冻结基线 M-REC-2025 与 Q01–Q18 待课题组确认；SSUI 为得分录入模式，等级为暂定演示分级；族总量无官方值不判定；“非建设用地生态用途”适用性未定；尚无实测修复后数据；场地 H 的材料与审核人均为模拟；产品无独立审核权限（职责分离需业主决定）；追溯页“证据链完整度”按各阶段全部材料角色计算，演示每阶段只上传一份模拟材料，显示 16%；安装包未签名；`data/raw` 公开历史处置由所有者决定。完整列表见 `KNOWN_LIMITATIONS_v1.2.2.md`。
