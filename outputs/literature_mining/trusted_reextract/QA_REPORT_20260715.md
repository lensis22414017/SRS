# 第14批文献训练数据紧急质量审计

## 结论

现有 `train_table_op_only_SOIL_CLEAN.csv` 与 `train_table_hm_op_SOIL_CLEAN.csv` 暂停作为正式训练输入。第二批提取产物缺少可验证单位，且旧管道存在低浓度重金属误删、无介质证据时默认 soil、按论文而非同一采样点判定 HM+OP、抗生素混入 OP 等系统性问题。

## 已确认问题

- `_all_raw_batch2.csv`：8,059 条记录，单位字段全部为 `Unknown`。
- `_batch2_cleaned_long.csv`：6,983 条记录，单位字段仍全部为 `Unknown`。
- 旧值域规则删除 0–1 mg/kg，会误删真实低浓度 Cd、Hg 等。
- 无解析目录、无 MD 或解析异常时，旧逻辑默认 `matrix=soil`。
- 旧逻辑按整篇论文同时出现 HM 与 OP 判为复合污染，可能把不同采样点伪拼为 HM+OP。
- 暂不纳入的抗生素记录共 51 条，已从正式 OP 污染物集合排除。
- 对第二批清洗长表重新按同一 `paper_id + sample_id` 核验，只有 31 个样点、12 个来源同时包含正式 HM 与正式 OP。

## 已完成修复

- 允许合法的低浓度 HM 正值，不再用数值大小猜测相关系数。
- 缺少介质证据时标记 `unknown`，不得默认 soil。
- 正式 OP 集合排除 SMZ、CTC、OTC、ENRO、SDZ。
- 增加训练证据完整性闸门：来源、样点、污染物、数值、明确单位、表格定位、soil 介质缺一不可。
- 通用表格提取器把表题/表体中的单位传播到逐条记录。
- HM+OP 判定改为同一采样点必须同时包含 HM 与 OP。

## 首批可信重提

从原生 SI 文件 `Legacy and Novel Per- and Polyfluoroalkyl Substances..._si_002.xlsx` 的 Table 2 提取：

- 124 个中国表层土壤样点；
- 74 种 PFAS；
- 9,176 条逐单元格证据记录；
- 单位全部为 ng/g；
- 每条记录定位到 `Table 2!单元格`；
- 0 值标记为 `below_detection`，不冒充实测浓度；
- 生成 124 行样点级宽表及 `x_measured_SumPFAS_ngg`。

## 训练决策

该 PFAS 数据只有一个文献来源，不能单独证明跨来源泛化，也不能据此替换现有生产模型。现阶段继续扩充可信 SI/原生表格来源；旧 SOIL_CLEAN 保留作审计对象，不进入正式模型替换。
