## 三、是否需要申请市场许可

| 许可类型 | 是否需要 | 说明 |
|---|---|---|
| **软件著作权登记** | ⚠️ 建议申请 | 国内发布建议登记软著(中国版权保护中心, ~1-3个月, 几百元), 权属证明+加分 |
| **ICP 备案** | 视部署形态 | 若部署公网 Web 服务需 ICP 备案; 桌面单机 exe 不需要 |
| **等保测评** | 视甲方要求 | 涉及环境监管数据, 甲方可能要求等保二级; 桌面单机通常不强制 |
| **应用商店上架** | 可选 | Microsoft Store 上架需开发者账号($19一次性); 桌面 exe 直接分发无需 |
| **代码签名证书** | ⚠️ 建议 | 避免 Windows SmartScreen 警告"未知发布者"(EV码签名证书 ~$200-400/年) |

## 四、协议与合规

### 软件许可(MIT)
- 允许: 商用/修改/分发/私用/再授权
- 唯一要求: 保留版权声明与许可证文本
- 免责: 无担保, 作者不承担任何责任
- ✅ 适合本系统(MIT 最宽松, 利于甲方验收与后续定制)

### 第三方依赖合规(见 NOTICE)
- 核心框架(FastAPI/React/scikit-learn/SHAP): 均为 MIT/BSD-3/Apache-2.0, 商用友好
- ⚠️ WeasyPrint: BSD-3, 但依赖 GPL 的 Pango/Cairo 系统库——动态链接 GPL 库的法律边界建议法务确认(学术/内部使用通常无争议)
- 数据: GEE 服务条款(非商业科研)、国标(公开标准, 可引用)

### 代码签名(强烈建议)
- 未签名 exe 在 Windows 触发 SmartScreen "未知发布者"警告, 影响甲方体验
- 申请 EV 代码签名证书(Sectigo/DigiCert, 需企业资质或个人开发者证明)
