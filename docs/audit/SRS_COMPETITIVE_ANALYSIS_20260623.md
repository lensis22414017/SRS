# SRS 竞品对比与深度完善清单

生成: 2026-06-23 | 基于 brief §2 四竞品 + SRS 真实闭环实测

## 一、竞品基准(brief §2)

| 竞品 | 核心能力 | 可借鉴 |
|---|---|---|
| **EQuIS/EarthSoft** | 环境数据全生命周期 + 现场/实验室 QA-QC + 标准交换格式 + ArcGIS/Power BI | QA/QC 自动校验流程、数据交换标准 |
| **ESdat** | 数据验证 + 合规报告 + 地下水趋势 + 化学表格 + 政府/监管适配 | 合规报告自动化、趋势分析 |
| **Locus EIM** | 分析数据管理 + 校验计算 + GIS + 修复工作流 + 审计追踪 | 修复工作流深度、审计完整性 |
| **Esri Environmental Monitoring** | 地图 + 实时监测 + 仪表盘 + AI/数据科学 + 云集成 | 实时监测、仪表盘、AI 集成 |

**竞品共识**: 数据可信+版本追溯是第一能力(非AI文案); 导入须有映射/校验/QA-QC/人工复核; 图表地图绑定真实数据版本; 推荐/结论须有规则标准证据; 写操作审计。

## 三、SRS 核心优势(差异化)

1. **RF+SHAP 障碍因子可解释识别** — 竞品多为统计/规则, SRS 用 ML+SHAP 解释(硕士论文级)。
2. **SSUI 可持续利用评价** — 中国方法文件本土化(竞品无)。
3. **GB15618/GB36600 中国标准内建** — 竞品多为欧美标准。
4. **五阶段监管追溯 + PDF 版本链** — 甲方验收闭环。
5. **lake model 含有机** — 三块(重金属/有机/复合)+数据湖训练(裴总根治), OP 闭环。

## 四、核心差距 + 深度完善清单(优先级)

### P0(甲方验收关键, 已达标)
- ✅ 真实数据闭环(非花架子): 深度测试 7 块全过。
- ✅ 数据版本追溯: sha256 贯通。
- ✅ OP 有机支持: GB36600 阈值 + lake model 含有机。

### P1(竞品差距, 建议补强)
1. **QA/QC 自动校验** (EQuIS 强): 平行样/加标回收/相对偏差自动判定 → validation_service 扩展。
2. **生产级存储** (PostGIS/MinIO): 当前 sqlite + 本地文件(MVP), 生产部署需切。
3. **地下水趋势分析** (ESdat 强): 时序浓度趋势 + Mann-Kendall → 新模块。
4. **实时监测/IoT** (Esri 强): 传感器接入 + 实时仪表盘 → WebSocket/时序库。
5. **GB36600 OCR 精确阈值** ✅ 已解决(2026-06-23): 四路交叉验证(GLM/Qwen3.5/4.5v/裴总核对)证明全部 LLM 对扫描表幻觉, 最终用裴总亲口核对权威值锚定 `data/standards/GB36600_有机阈值_权威.csv`(factor 精确匹配 ORG_COLS_MAP), 详见 `docs/audit/GB36600_OCR_交叉验证报告_20260623.md`。

### P2(生态, 长期)
6. **移动端/现场采集** (EQuIS): PWA/小程序。
7. **API 生态 + 第三方集成**: 开放 API + Webhook。
8. **多租户/协作**: 企业隔离已部分, 需增强并发。
9. **更多含理化指标的数据集** (model 泛化): 当前 OP 理化稀疏(SSUI None), 找更多含 pH/有机质/氮磷钾的数据。

## 五、诚实约束(本次未达)
- **OCR 阶段 A**: omlx GLM-4.7-Flash 对 GB36600 扫描表格不返 JSON(0 项) → 用 fallback 保守阈值(苯并芘550/多环芳烃550/DDT400 ng/g), OP 标签 17%/推荐 4 条工作正常。精确阈值待更可靠 OCR 或裴总提供标准文本。
- **SSUI 有机场地**: 北京/海南 OP 无理化指标 → SSUI None(诚实, 裴总确认不管)。
- **model AUC 0.99+ 虚高**: 标签由阈值派生 + __missing 标记 → 已知, 待真实标注数据改善。
