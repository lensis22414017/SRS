## 四、数据使用建议
1. 缺失率 > 95% 的列建模前剔除（如 CEC/EC_T/BS_T 等），其余数值列中位数填充并保留 `*_missing` 标记。
2. 偏态明显的列优先用中位数代表集中趋势；建模可考虑对数变换。
3. 异常点（IQR 法）需人工复核，污染场地高值多为真实超标而非错误，**不可一律剔除**。
4. 完整逐列指标见 `data/processed/training_eda_profile.csv`。
