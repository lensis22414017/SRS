# SRS v1.2.2 迁移与回退说明

## 升级（v1.2.1 / v1.2.0 / v1.1.0 → v1.2.2）
1. 关闭 SRS；复制 `%APPDATA%\SRS` 整个目录作为备份（便携版复制 `SRS\SRS_data`）。
2. 运行 `SRS-Setup-1.2.2-Windows-x64.exe` 覆盖安装（安装目录不变）。
3. 本版**没有**新的数据库迁移，不改写任何已有记录：
   - 旧版入库的课题三 SSUI 若原值 >1（v1.2.1 记为“高度可持续”），升级后读取即显示“超出有效域，不分级”，利用结论不再据此给出支持；原等级以 stored_grade 留存。
   - 旧版诊断中由“族→代表物”映射得到的阈值（如邻苯二甲酸酯总量按 DEHP 判定）只存在于旧诊断记录；请对相关场地**重新运行障碍因子分析**，并重新生成报告。
   - 利用结论接口要求明确用途；旧调用方未传农用地类型/生态用地类别时得到 needs_manual_use_selection。
4. 已生成的 v1.2.1 报告与快照仍可下载、快照校验仍有效（快照记录的是生成时的内容）。

## 回退（v1.2.2 → v1.2.1）
1. 卸载 v1.2.2（不删除用户数据）；安装 v1.2.1-rc.1 安装包。本版无结构迁移，可直接回退；回退后 v1.2.2 期间新生成的记录（如五阶段附件、阶段→证据字段）仍在库中，v1.2.1 读取时忽略新增字段。
2. 如需完全回到升级前状态，用升级前备份覆盖 `%APPDATA%\SRS`。

## 验证
- GitHub Actions Windows：v1.1.0 → v1.2.2、v1.2.1 → v1.2.2 两条升级路径（Windows 验收证据 `acceptance_upgrade*.json`），其中 v1.2.1 路径在旧版写入 SSUI 1.019189 后检查升级后不分级、不支持。
