# SRS v1.2.2 年度验收演示操作脚本（收尾候选）（汇报人 / 操作员）

> 演示数据全部为固定种子（20261009）生成的合成数据，标签“模拟数据——仅供测试/演示”。只导入**独立演示库**（新装或便携版），不得导入正式库，不得用于正式报告。
> 时长约 28 分钟。左列为操作员动作，右列为汇报人口述要点。每一步都先说明使用的是**修复前**还是**修复后**数据。

## 2 课题一：障碍因子识别（3 分钟）—— 修复前数据

| 操作员 | 汇报人 |
|---|---|
| 场地管理 → 数据导入 → 选 `site_A/01_MCDEMO-A_修复前检测数据_…xlsx` → 导入 | 系统自动识别字段并给出校验报告；场地编号由系统分配（`SRS-A`） |
| 打开场地 → 障碍因子分析（课题一）→ 选生产轨道 → 运行诊断 | KOS = B×(0.30R+0.25W+0.15M+0.20S+0.10E)；**正式 Top-N** 只收录 GB 15618 官方筛选值超标因子（镉、铅、铜、砷、锌） |
| 下拉到“探索性提示（待复核）” | 阳离子交换量、全氮为**下限**指标，低于文献参考值才提示“不足”；高值不再被当作障碍；有机质与有机碳分开、不换算 |
| （可选）导入 `cases_v121/01_MCDEMO-G_…xlsx` → 运行诊断 | 重金属均未超标 → 正式排名显示“证据不足”，不会用文献参考值填补 |
| （可选）导入 `cases_v122/P/01_MCDEMO-P_邻苯二甲酸酯_…xlsx` → 生态轨、第一类用地 → 运行诊断 | 邻苯二甲酸二(2-乙基己基)酯 50 mg/kg 对照**自身**官方值 42（CAS 117-81-7）→ 正式障碍；邻苯二甲酸二正辛酯 50000 μg/kg 换算为 50 mg/kg 对照自身值 390 → 不超标；“邻苯二甲酸酯总量”无官方总量值 → 不判定；邻苯二甲酸二甲酯未登记 → 待人工复核。改为第二类用地 → 无正式障碍 |

## 4 课题三：修复后 SSUI（4 分钟）—— 修复后数据

| 操作员 | 汇报人 |

## 5 五类利用结论（4 分钟）

| 操作员 | 汇报人 |
|---|---|
| 场地 `SRS-A` → 修复后利用结论 → **不选用途**直接运行 | 结论为“需人工选择用途”：只显示假设性保守筛查，不作正式结论 |

| 农用地类型“水田”、生态用地类别“第一类用地” → 运行判定 | 生产、生态门禁均通过 → **生产与生态均支持**（用途已明确） |
| 若时间允许：依次导入 `site_B…site_E` 的 01–04 文件（或展示预先导入好的演示库） | B 支持生产；C 支持生态；D 均不支持（超管制值）；E 证据不足 |
| 打开 `SRS-D` 结论页 | 超管制值的一轨不能被任何评分抵消；列出超标因子、点位数、所用标准 |
| 打开 `SRS-E` 结论页 | 必测项目缺测 → 证据不足，并列出需补充的证据 |

## 7 结束语要点（如实表述）

1. 软件与演示：v1.2.2 收尾候选版；SSUI 定义域外不分级、邻苯二甲酸酯单体按 CAS 绑定、用途未明确不作正式结论；场地 H 完整演示推荐与五阶段追溯（模拟材料）。Windows 安装、重启、v1.1.0/v1.2.1 升级、便携版在 GitHub Actions 虚拟机上实测，标准账户结果单独列出。
2. 科学方法：按冻结基线执行，Q01–Q18 待陈亮、宋伟杰老师确认；本版未新增阈值；文献参考阈值未批准为正式限值；尚不构成科学验证。
3. 真实修复后验证：尚无实测修复后数据，未开始。经济输入 JSON 不参与 SSUI。

## 应急处理

| 现象 | 处理 |
|---|---|
| 浏览器未自动打开 | 手动访问 `http://127.0.0.1:8000`（默认端口；以启动窗口显示为准） |
| 端口被占用 | 关闭其他 SRS 实例；或 `SRS.exe --port 18080` |
| 预览报“场地编号不一致” | 演示文件 B2 应为空；若被改动，清空 B2 或填系统显示的场地编号 |
| 需要重来 | 退出程序，删除便携版 `SRS_data` 目录（仅演示库！），重新启动 |
