# SRS v1.2.2 已知限制

本版为**收尾候选版（预发布）**。v1.2.1 的已知限制除下列已更新条目外继续有效（见 `KNOWN_LIMITATIONS_v1.2.1.md`）。

## A 科学方法（不构成科学验证）
1. 课题二冻结基线 M-REC-2025；Q01–Q18 待课题组确认。本版**没有**等待签字，也没有新增或修改任何阈值、权重、等级区间。
2. 课题三 SSUI 等级只在方法文件定义的 [0, 1.0] 内给出，且为**暂定演示分级**（0.6 支持阈值暂定）；域外值的解释（是否截断、是否扩展等级）需课题三负责人决定（Q 列表）。
3. 族总量（如“邻苯二甲酸酯总量”“二甲苯(总)”“氯酚类”）在 GB 36600 中无官方总量值，系统不判定；只有标准中明确给出的总量限值（GB 15618 六六六总量、滴滴涕总量；GB 36600 多氯联苯(总量)等）才参与判定。未登记的单体进入“未映射/待复核”。
4. “非建设用地生态用途”的法规适用性（是否参照 GB 36600 第一类用地）未确定，系统给出 regulatory_applicability_unresolved，不作推定。

## B 数据
1. 尚无实测修复后数据；修复后结论只在合成数据上演示。
2. 场地 H 的五阶段材料、审批意见、审核人均为**模拟**（文件名与水印“模拟材料——仅供测试/演示, 非真实审批文件”），不代表任何真实单位、人员或批复。

## C 软件与权限
1. 产品没有独立的“审核”权限：具备 data:input 的企业/第三方机构用户也能把阶段标记为完成。演示中审核动作由管理员角色的“模拟审核员”执行；是否增加 workflow:review 权限实现职责分离，需业主决定（会改变现有用户权限）。
2. 管理员导入的场地不归属任何企业（企业用户看不到）；需由管理员分配。企业用户导入的新场地归属其企业（v1.2.2 修复）。第三方机构用户导入的场地仍需通过“项目授权”访问。
3. Windows 验收在 GitHub Actions 虚拟机上执行；标准账户以计划任务身份运行，不等同真人在甲方 Windows 10/11 上交互测试。`Start-Process -Credential` 跨会话启动失败为诊断记录，单独列出。
4. 源码仓库公开；`data/raw` 历史中含甲方原始工作簿，是否改写历史需所有者决定（本版未改写）。
