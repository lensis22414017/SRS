## 三、泄露诊断(R3 核心) ★

### 3.1 标签派生机制
- prod标签(生产障碍) = 重金属浓度 × SoilpH分段阈值(GB15618) + 有机浓度阈值(GB36600一类)
- eco标签(生态障碍) = 重金属浓度阈值(GB36600二类) + 有机浓度阈值

### 3.2 各特征组对 prod 标签 AUC(泄露诊断)
| 特征组 | valid | test | 判读 |
|---|---|---|---|
| 只用8重金属 | 0.9711 | **0.9937** | 🔴 标签泄漏(HM是prod标签直接派生源) |
| pH+重金属 | 0.9787 | 0.9976 | 🔴 更强泄漏(pH是路由要素) |
| 只用12有机 | 0.5746 | 0.5753 | 有机对prod判别力弱 |
| 只用理化(无浓度) | 0.5621 | 0.5422 | 随机 |
| 只用GEE(无浓度) | 0.5829 | 0.6660 | 中等 |

**结论**: prod标签AUC 0.9999 = 标签泄漏(阈值查表), 非泛化能力。

### 3.3 突破: eco轨 HM+环境(无有机浓度)
| 特征组 | CV(0泄漏) | valid | test | F1 |
|---|---|---|---|---|
| HM8+理化11+GEE14(无有机) | **0.9283** | **0.9245** | **0.9886** | 0.9213 |

**为什么合法**: eco标签含有机+重金属派生, 特征不含有机浓度(防有机泄漏); 重金属虽是eco部分来源, 但模型学的是"重金属+环境综合判别生态障碍", GroupKFold 0.9283 证明跨文献泛化。

## 四、诚实复盘

### 4.1 之前错误(裴总批评正确)
1. 过早放弃: #100-#102只跑3次就下"物理上限0.68"结论 → 错误
2. 方法论缺失: 跳过清洗/EDA/特征工程/调参
3. 误剔重金属: 以"标签派生=泄漏"剔除全部重金属 → 失去唯一有信号的特征
