# 功能重构可行性评价

**版本** v0.1 ·**日期** 2026-06-10 ·**作者** 项目组 ·**状态** 草稿
**参数来源**:《(2025年)污染场地土壤生态-生产功能障碍识别与重构利用的评价方法+年度报告.docx》,已固化至 `ml/params/evaluation_params.json`(`extract_params.py` 生成,勿手改)。

## 1. 方法

改进的模糊综合评价法。区分**生产功能**与**生态功能**两套指标体系与权重。

综合得分:**T_total = Σ ( F_i × W_i )**,其中 F_i = 指标分等赋值(0–100),W_i = 指标权重。
等级(表2.23):**T > 50 → 可行;T ≤ 50 → 不可行**。

权重由主观(AHP,CR<0.1 一致性检验通过)+ 客观(熵权法/CRITIC)+ 博弈论组合赋权得到。土壤质量类/修复潜力类指标缺失时,可用综合指数法/内梅罗指数法:`P = sqrt((P_mean² + P_max²)/2)`。

## 3. 分等赋值(表2.22 摘录)

- pH(生产):≤5或≥9→20;5–5.5/8.5–9→40;5.5–6/8–8.5→60;6–6.5/7.5–8→80;6.5–7.5→100。
- 有效土层厚度:<30cm→10;30–60→50;60–100→70;100–150→90;≥150→100。
- 污染物(生产):超管制值→10;超筛选值未超管制→50;未超筛选值→100。
- 污染物(生态):超第一类用地管制值→10;超筛选未超管制→50;未超→100。
- 全氮/有效磷/速效钾/CEC 按旱地/水田分档(10/50/100)。
完整 41 项(生产 18 + 生态 23)见 JSON `reconstruction.scoring`。

## 4. 输出契约

`evaluation_results`(eval_type = `reconstruction_prod` / `reconstruction_eco`):score、grade(可行/不可行)、dimensions(各指标 F 与加权分项)、weights(权重快照)、limiting_factors(低分关键指标)、param_version、data_version、explanation。
