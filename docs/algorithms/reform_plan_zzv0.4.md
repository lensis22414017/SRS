# 障碍因子识别模型方法学整改方案 (zzv0.4)

> 日期: 2026-07-01 | 基于: 深度评估文档 + 36篇RIS文献 + 裴总纠正 + SRS需求基线
> 状态: 待裴总确认后执行

## 一、裴总的纠正(辛特助理解偏了的根本点)

裴总原话: "我们主要不是预测风险，而是找污染场地的关键障碍因子，所有内容都要围绕是否障碍、障碍高度是多少来回答，而不是用环境+遥感预测重金属和有机浓度"

**辛特助之前的错误**: 把障碍因子识别当成了"二分类预测任务"(是否超标)，纠结浓度是泄漏还是合法特征，追求 AUC 0.99。

**正确理解(对照 SRS.md:118 FR-DEC-01 + rf_shap.md:15-17)**:
- 障碍因子识别 = **因子归因任务**(factor attribution)
- 用户上传场地实测数据(measurements: 浓度+pH+理化等因子值)
- RF 学习"因子组合→功能障碍"的关系，SHAP 解释"每个因子对障碍的贡献"
- **核心输出不是"是否障碍"(那是规则引擎的事)，而是"哪些因子是障碍、障碍多高"(SHAP值)**
- 科学价值 = 可解释的因子归因，而非黑箱预测分数

## 二、任务定义三层分离(文档第19-29行要求)

按深度评估文档要求，把混在一起的任务拆成三层:

### 第一层: 原始观测层(只读)
- 污染物实测值、pH、理化、坐标、采样时间、来源文献
- 数据源: measurements 长表(用户上传) + 训练集 merged_std33
- 原则: 只读、可追溯、不可被训练改写

### 第二层: 规则派生层(标签来源)
- 标签 = GB15618/GB36600 阈值规则派生(任一因子超阈值→障碍=1)
- **这一层是规则引擎，不是 ML 标签**
- 文献支撑: Rudin 2019 — 高风险场景优先用规则/可解释模型，不依赖黑箱

### 第三层: 训练任务层(ML 价值所在) ★
这才是 ML 真正的价值——不是复现规则(规则引擎更准)，而是:
- **因子归因**: RF+SHAP 量化每个因子对"障碍"的边际贡献(SHAP值)
- **障碍高度量化**: SHAP |mean_abs| 排名 = 因子的"障碍高度"
- **影响方向**: SHAP 正/负 = 促进/缓解障碍
- **跨场地泛化的归因模式**: 不同地区/污染类型，主导障碍因子是否不同

> 关键: 浓度作为特征在这里完全合法——因为用户实测时拿到的就是浓度，模型要解释的是"这些浓度里哪些是障碍"。这不是泄漏，是归因任务的输入。

## 四、整改路线(按文献优先级)

### Phase 1: 冻结任务定义(文档第一步)
- 明确写: 障碍因子识别 = 因子归因任务(RF+SHAP)，不是预测任务
- 标签 = 规则派生(GB阈值)，模型价值 = 归因解释
- 输出契约: Top-N因子 + SHAP贡献度 + 影响方向 + 不确定性区间

### Phase 2: 建立三套基线(文档第二步)
1. **规则引擎基线**: 按GB阈值直接判定(最强可解释，AUC=1.0但有意义=规则复现)
2. **可解释统计基线**: EBM(ExplainableBoostingMachine)或逻辑回归(Rudin 2019推荐)
3. **树模型基线**: RF/HGB(当前zzv0.3，SHAP归因主力)
- 三者在同一GroupKFold评估协议下对比

### Phase 3: 嵌套CV + fold内预处理(文档第三/四步)
- 外层: GroupKFold(按DOI/Source)估泛化误差
- 内层: GroupKFold调超参(Probst 2019: 只调max_features/min_samples_leaf)
- 预处理全进Pipeline(scikit-learn要求，防跨边界泄漏)
- 阈值用内层valid选(PR曲线F1最优点)，不用默认0.5

### Phase 4: 缺失治理ablation(文档第五步)
- A: 仅完整覆盖特征
- B: fold内简单填充+missing indicator
- C: 模型化填充(RF插补)
- D: 缺失感知树模型(当前)
- 比较外层GroupKFold下哪个真改善

### Phase 5: 可解释性三层(文档第47-55行)
- **第一层规则解释**: 先告诉用户"障碍由哪些阈值规则判定"
- **第二层全局解释**: SHAP + permutation importance + ALE(相关特征用ALE不用PDP)
- **第三层局部解释**: 单场地的关键因子+不确定性区间(共形预测)

### Phase 6: 模型卡+数据卡+标签审计
- 模型卡(Mitchell 2019): 训练数据/性能切片/局限性/使用边界
- 数据卡(Gebru 2018): 数据来源/缺失分布/已知偏差
- 标签审计(Northcutt 2021): confident learning 排查疑似错标

## 五、对甲方的解释口径(裴总的核心关切)

**甲方可信的解释**(基于规则层+SHAP归因):
> "该场地诊断为障碍场地。根据 GB15618-2018 国标阈值规则，镉(实测0.8mg/kg)超过筛选值(0.3mg/kg)，砷(实测35mg/kg)超过筛选值(30mg/kg)。RF+SHAP 归因分析显示: 镉是首要障碍因子(SHAP贡献度0.52)，其次为砷(0.18)、铅(0.12)。这意味着修复应优先针对镉污染。"

这个解释:
1. ✅ 基于国标规则(可审计、可复现)
2. ✅ SHAP归因有量化依据(不是黑箱)
3. ✅ 指导修复决策(因子优先级)
4. ✅ 有科学发现价值(不同场地主导因子不同 = 科学洞察)
