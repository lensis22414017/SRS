# 可持续利用评价:SSUI

**版本** v0.1 ·**日期** 2026-06-10 ·**作者** 辛特助 ·**状态** 草稿
**参数来源**:同方法文件,固化至 `ml/params/evaluation_params.json` 的 `ssui` 段。

## 1. 模型

分维度多指标分块赋权的土壤持续利用度(SSUI)。维度:安全性 B1(限制因子 C1 + 风险因子 C2)、经济性 B2(经济成本 C3 + 经济效益 C4)。

**SSUI = ( Σ vC_i · SC_i ) · f(t) · M**

- SC_i:各维度组内元指标 Min-Max 归一化后线性加权得分(正向指标正向化,负向指标负向化)。
- vC_i:维度顶层权重(重标化使和=1)。
- f(t):时间权重函数 **f(t) = 1 + α·t**,α = 0.03,t = 相对基准跨度(年)。文件实证 t=2 → f(t)=1.06。
- M:管理调节因子(表3.49)。

## 2. 权重(实证口径,未纳入风险因子 C2 时)

顶层重标化(JSON `ssui.top_weights_*`):
- 生产:vC1(限制)0.431218、vC2(成本)0.259357、vC3(效益)0.309425。
- 生态:vC1 0.446851、vC2 0.270695、vC3 0.282454。

元指标权重(表3.53 生产 / 3.54 生态,JSON `ssui.{production,ecology}.meta_weights`),例(生产):
- 限制因子 C1:含盐量 0.3856、pH 0.2218、氮磷钾 0.1789、有机质 0.1115、CEC 0.1020。
- 经济成本 C3:劳动力 0.4350、机械化 0.3330、土地成本 0.2320。
- 经济效益 C4:土地生产率 0.4073、土地产出系数 0.3235、人均可支配收入 0.2692。

完整含风险因子的 25 元指标体系(表3.53/安全性 D1–D17 + 经济性 D18–D25)亦在 JSON,MVP 先用实证三组口径,风险因子待数据齐备启用。

## 3. 管理调节因子 M(表3.49)

生态利用:低 1.05 / 中 1.075 / 高 1.10;生产利用:低 1.10 / 中 1.15 / 高 1.20。
默认(实证):生产 M=1.15,生态 M=1.08。

## 4. 等级(表3.50)

SSUI 0.8–1.0 高度可持续;0.6–0.8 中度;0.4–0.6 低度;<0.4 不可持续。

## 5. 输出契约

`evaluation_results`(eval_type=`ssui`):score(SSUI)、grade、dimensions(SC1/SC2/SC3 及元指标分项)、weights、limiting_factors、risk_factors、param_version、data_version、explanation(含 f(t)、M 取值)。

## 8. 已实现(2026-06-10)

`ml/evaluation/ssui.py`(纯 python)。按裴总确认采用**安全性-限制因子 C1 单维度口径**:Min-Max 归一(含盐量负向、其余正向)+ 组内重标化,SSUI = SC1·f(t)·M,上限截断 1.0,等级按表3.50。结果明确标注未纳入风险因子 C2 / 经济成本 C3 / 经济效益 C4(个旧无相应实测)。

个旧实证:**SSUI=0.5284 低度可持续**(SC1=0.4335,f(t)=1.06@t=2,M=1.15 生产中等强度,参评元指标 pH/有机质/氮磷钾)。结果已入 `evaluation_results`(eval_type=ssui)。
