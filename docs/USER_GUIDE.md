# 污染场地土壤生态-生产功能重构监管系统（SRS）— 首次使用说明

> **版本**：v1.0.0 | **适用**：Windows 10/11 64位 | **机构**：生态环境部土壤与农业农村生态环境监管技术中心

---

## 一、安装

### 1.1 系统要求
- Windows 10 或 Windows 11（64位）
- 至少 1GB 可用磁盘空间（程序+数据）
- 内存 ≥ 4GB（推荐 8GB，大数据量场地更流畅）
- 无需联网（离线可用）；联网可启用 AI 问答和卫星影像地图

### 1.2 安装步骤
1. 获取安装包 `SRS_Setup_v1.0.0.exe`
2. **右键 → 以管理员身份运行**（安装到 Program Files 需要管理员权限）
3. 按安装向导操作：
   - 欢迎页面 → 下一步
   - 许可协议 → 接受
   - 安装路径 → 保持默认（`C:\Program Files\SRS`）或自定义
   - **勾选"在桌面创建快捷方式"**
   - 安装 → 等待约 1-2 分钟（解压依赖文件）
   - 完成 → 勾选"立即启动"
4. 安装完成后，桌面出现「污染场地监管系统」图标

### 1.3 卸载
- 开始菜单 → SRS → 卸载 SRS
- 或：设置 → 应用 → 找到 SRS → 卸载
- **注意**：卸载不会删除你的场地数据（存储在 `C:\Users\<用户名>\AppData\Roaming\SRS\`）。如需完全清除，请手动删除该目录。

## 二、首次登录

### 2.1 首次启动设置（生产环境）

**生产环境首次启动**时，系统不预置任何默认账户。首次访问会自动进入**管理员设置向导**：

1. 双击桌面图标启动系统
2. 系统自动打开浏览器，检测到未初始化 → 跳转到「系统首次启动」向导
3. 设置管理员用户名（至少 3 字符）和密码（至少 8 位，含大小写字母和数字）
4. 确认密码 → 点击「完成设置并创建管理员」
5. 创建成功后 → 跳转登录页，用刚设置的账号登录

> ⚠️ **安全提示**：管理员账号拥有系统全部权限，请妥善保管密码。生产环境不预置任何默认凭据。

### 2.2 演示/测试环境账户

**仅在演示模式（SRS_DEMO_SEED=1）下**预置以下测试账户（生产环境不适用）：

| 角色 | 用户名 | 密码 | 权限 |
|---|---|---|---|
| **管理员** | `admin` | `Demo@2026` | 全部功能（含系统管理） |
| 监管人员 | `regulator` | `Demo@2026` | 审批、追溯、报告 |
| 企业用户 | `enterprise` | `Demo@2026` | 数据导入、查看（无系统管理） |
| 第三方机构 | `agency` | `Demo@2026` | 检测/评估数据上传 |

### 2.3 登录步骤
1. 双击桌面图标启动系统
2. 系统自动打开原生窗口（无浏览器地址栏）
3. 输入用户名和密码 → 登录
4. 首次启动会有约 5-10 秒初始化（自动建表+加载数据库），请稍候

## 三、基本使用流程

### 3.1 完整工作流（从数据到报告）
```
数据导入 → 数据EDA → 障碍因子诊断(KOS) → 功能重构评价 → 方案推荐 → 全流程追溯 → 生成报告
```

### 3.2 导入场地数据
1. 进入「场地管理」→ 点击「导入数据」
2. 上传 Excel 检测数据表（.xlsx）
3. **字段映射**：将 Excel 列映射到系统因子（系统会自动猜测，可手动调整）
   - ⚠️ 注意：**不要把"上限""下限""筛选值""管制值"映射为因子**，这些是阈值参考列
4. 确认映射 → 导入
5. 导入后可在「场地管理」看到新场地，点击进入详情

### 3.3 查看数据分析（EDA）
1. 进入场地详情 → 「数据分析(EDA)」标签页
2. 查看各因子的统计描述（均值、中位数、CV、偏度、异常点）
3. 可按列排序、翻页（序号连续不重置）
4. 异常值检测（IQR + Z-score 双法）

### 3.4 运行障碍因子诊断（KOS）
1. 进入「障碍因子诊断」页面
2. 选择场地和诊断轨道：
   - **生产轨**（GB15618 农用地标准）
   - **生态轨**（GB36600 建设用地标准）
3. 点击「运行 KOS 诊断」
4. 查看结果：
   - **第一层**：明确障碍因子（实测+超标+高证据等级）
   - **第二层**：KOS 综合评分排名（规则主导 30%R + 用途权重 25%W + 模型辅助 15%M + 稳定性 20%S + 证据 10%E）
   - **模型贡献度**：SHAP 归一化贡献（模型全局贡献份额，辅助参考，非因果、非障碍高度）

> 📌 **结果范围说明**：正式超标结论仅限于身份明确、单位兼容且阈值适用的因子。对没有适用阈值或未被正式因子库收录的实测指标，系统通过模型候选识别、族群级近邻分析和未知因子预警进行辅助识别，不会丢弃数据或强行套用标准。探索性识别结果不等同于法规超标判定，需结合检测方法和专家复核。当前已完成 **3 个原始场地的工程回归验证 + 15 个合成数据演示**，结论作为辅助决策依据，不构成监管级科学可信判定。方法学采用规则、模型和开放集识别相结合的混合策略（非纯数据驱动）。AI 润色文本经事实校验但仍有降级回退机制，以原始检测数据为准。

### 3.5 功能重构评价
1. 进入「功能重构」页面
2. 选择场地 → 运行评价
3. 查看生产轨/生态轨双轨得分、短板仪表盘

### 3.6 方案推荐
1. 进入「方案推荐」页面
2. 系统根据障碍因子自动匹配修复技术
3. 查看方案综合评分对比、禁用条件、成本周期

### 3.7 全流程追溯与报告
1. 进入「全流程追溯」→ 选择场地
2. 初始化五阶段流程（调查评估→方案审批→修复施工→效果评估→后期管护）
3. 每阶段可上传材料、推进/退回
4. 点击「生成 PDF 报告」→ 自动生成追溯报告（含诊断/评价/推荐/采样点图/模型全局贡献份额图）

## 四、常见问题

### Q1：启动后窗口空白/打不开？
- 等待 10-15 秒（首次启动需初始化数据库）
- 检查任务管理器是否有 `SRS.exe` 进程在运行
- 如果端口 8000 被占用，关闭占用程序后重试

### Q2：AI 问答没反应？
- AI 功能需要网络连接（调用智谱 GLM 大模型）
- 如系统提示"AI 未配置"，检查网络或联系管理员配置 API key

### Q3：地图不显示卫星影像？
- 卫星影像需要联网（高德地图瓦片）
- 离线状态下只有行政区矢量底图（正常显示）

### Q4：报告生成失败或内容为空？
- 报告内容依赖诊断/评价/推荐结果。请先完成障碍因子诊断，再生成报告
- 未运行诊断的场地，报告对应章节会显示"请先执行诊断后重新生成"

### Q5：退回功能怎么用？
- 在全流程追溯页面，某阶段状态为"已完成"时，可点击「退回」按钮
- 退回后该阶段回到"已退回"状态，可重新进入"进行中"修改

### Q6：如何导入演示数据？
- 演示数据 Excel 在安装目录的 `demo_sites` 文件夹（或随安装包提供）
- 按正常「数据导入」流程导入即可
