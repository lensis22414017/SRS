## 企业数据隔离流程

```mermaid
sequenceDiagram
    participant U as 用户
    participant API as FastAPI 路由
    participant DEPS as deps.py (鉴权)
    participant DB as PostgreSQL

    U->>API: GET /api/v1/sites (JWT Header)
    API->>DEPS: get_current_user()

    DEPS->>DB: 查询 users 表 (by JWT sub)
    DB-->>DEPS: user {id, organization_id}

    DEPS->>DB: 查询 user_roles + role_permissions
    DB-->>DEPS: permissions_set {data:query, ...}

    DEPS-->>API: user 对象 + permissions

    alt 企业用户 (enterprise)
        API->>DEPS: scope_sites_query(user, query)
        DEPS-->>API: query.filter(sites.organization_id == user.org_id)
    else 管理员 (admin)
        API->>DB: 无隔离，查询全部场地
    else 第三方/监管
        API->>DB: 按授权范围/监管范围过滤
    end

    DB-->>API: 过滤后的场地列表
    API-->>U: JSON 响应 (仅可见场地)

    Note over U,DB: 单场地访问时同样执行 assert_site_access()
```

## RBAC 实现要点

| 层次 | 实现 | 位置 |
|------|------|------|
| **数据库** | 5 表: `users`, `roles`, `permissions`, `user_roles`, `role_permissions` | `backend/app/models/__init__.py` |
| **种子数据** | `seed_db.py` 初始化 4 角色 + 14 权限 + 3 测试用户 | `backend/app/db/seed_db.py` |
| **认证** | JWT (HS256) + bcrypt 密码哈希 | `backend/app/core/security.py` |
| **鉴权依赖** | `get_current_user()` / `require_permission(code)` / `assert_site_access()` | `backend/app/core/deps.py` |
| **前端路由守卫** | `<Protected>` 组件检查登录状态; `/system` 路由 `<AdminOnly>` | `frontend/src/App.tsx` |
| **前端 API** | axios 拦截器注入 JWT; 401 自动跳转登录页 | `frontend/src/api/client.ts` |
