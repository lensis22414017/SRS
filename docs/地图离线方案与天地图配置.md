# 地图离线方案与地图服务配置指南

> 本文档说明 SRS 系统的地图方案：**默认离线行政区底图（开箱即用，无 key/无外网）** + **可选在线影像底图（高德，换电脑/换网络均可用）** + **可选离线影像 MBTiles（按区域导入）**。
> 适用于服务器部署、桌面打包（exe/dmg）分发、内网/断网场景。

---

## 一、方案总览（三层架构）

| 层级 | 内容 | 体积 | 来源 | 是否依赖外网 | 用途 |
|------|------|------|------|------------|------|
| **L1 矢量底图（默认）** | 全国省/地市/县行政区边界 | ~27MB | 阿里 DataV 开放数据 | ❌ 完全离线 | 开箱即用，行政区轮廓+采样点 |
| **L2 影像 MBTiles（可选）** | 指定区域卫星影像 | 按区域(几百MB-数GB) | 地图服务（需 key） | 仅下载时 | 桌面版按需导入，离线查看 |
| **L2 高德在线影像（推荐在线方案）** | 卫星影像+中文注记 (hybrid) | 0 | 高德地图 AutoNavi | ✅ 需外网 | **无 IP 白名单**，换电脑/换网络不受影响 |
| **L2 地图服务在线影像（可选）** | 地图服务实时卫星影像 | 0 | 地图服务（需 key+IP白名单） | ✅ 需外网+固定IP | 仅服务器固定部署时可用 |

**核心结论**：
- **桌面打包版（exe/dmg）默认只用 L1**，完全离线，开箱即用，**不需要任何 key、不需要白名单、不需要外网**。
- 用户点击"🛰 影像"按钮后按需加载高德卫星影像（**无 IP 白名单**，换电脑/换网络均可用，含中文标注）。
- 地图服务需固定 IP 白名单，桌面打包/多地演示场景**不推荐**。
- 报告里的地图图件用 matplotlib 离线渲染（不依赖任何在线地图），**内网也能生成带图报告**。

## 二、L1 离线行政区底图（已内置）

### 数据内容
- 全国 **35 个省级行政区** + **475 个地级市** + **2728 个县/区** 边界。
- 三级金字塔懒加载：缩放 1-5 级显示省界，6-8 级显示地市，9+ 级显示县。
- 数据源：阿里 DataV.GeoAtlas（公开开放数据，可商用）。

### 文件位置
```
data/geo/
├── china_provinces.json     # 全国省界(569KB)
├── prefectures/             # 各省地级市(33个文件, 3.7MB)
├── counties/                # 各地级市的县(329个文件, 22MB)
└── geo_index.json           # 行政区索引(adcode→名称→bbox)
```

### 数据更新/重建
```bash
# 全量下载(省+地市+县) + 重建索引
backend/.venv/bin/python scripts/download_admin_boundaries.py

# 仅重建索引(不重新下载)
backend/.venv/bin/python scripts/download_admin_boundaries.py --rebuild-index
```

### 后端 API
- `GET /api/v1/map/geo/index` — 返回行政区索引（轻量，无几何）
- `GET /api/v1/map/geo/boundaries?level=province` — 全国省界
- `GET /api/v1/map/geo/boundaries?level=prefecture&adcode=530000` — 云南省地市
- `GET /api/v1/map/geo/boundaries?level=county&adcode=532500` — 红河州县级

## 三、L2 高德在线影像底图（推荐，无 IP 白名单）

**适用于所有有外网的场景**：服务器部署、桌面打包、换电脑演示均可用。

### 特点
- **无 IP 白名单**：只需 domain 绑定（`lbs.amap.com`），换公网 IP 不影响。
- style=8 hybrid：一次请求同时返回卫星影像+中文地名/道路/村镇注记，**甲方不懂英文无压力**。
- 30 万次/天免费配额（日常演示远不会触及上限）。
- 不配置 key 时走公共通道，同样可用；配置后享官方配额保障。

### 申请 key
1. 访问 https://console.amap.com/
2. 控制台 → 应用管理 → 创建新应用 → 添加 Key（类型选 **Web 服务**）
3. 将 key 填入 `deploy/.env`

### 配置步骤

```bash
# deploy/.env 或服务器环境变量
GAODE_KEY=你的高德key   # 不填也能跑, 填了享配额保障
```

前端走后端代理 `/api/v1/map/tile/gaode/{z}/{x}/{y}`，key 不暴露浏览器。

### 前端切换逻辑
- 默认：矢量底图（L1，离线，无 key）
- 用户点"🛰 影像"→ 按需加载高德 hybrid 瓦片
- 用户点"🗺 矢量"→ 移除瓦片，回到矢量底图
- 瓦片加载失败时：前端显示告警提示，矢量底图保持可用

### 故障排查
| 现象 | 原因 | 解决 |
|------|------|------|
| 影像全灰 | 无外网 | 切回矢量底图即可; 矢量始终离线可用 |
| 高德 403 | key 无效或超配额 | 检查 GAODE_KEY 或申请新 key |
| 后端 502 | 代理超时(网络慢) | 检查服务器到 autonavi.com 连通性 |

## 三b、L2 地图服务在线影像（可选，需 key + 固定 IP 白名单）

⚠️ **仅适用于服务器固定部署且有外网的环境**。桌面打包版/换地演示场景**不推荐**。

### 配置步骤

```bash
# deploy/.env 或服务器环境变量
TIANDITU_KEY=你的地图服务key
```
前端走后端代理 `/api/v1/map/tile/img/{z}/{x}/{y}`，调用方是服务器。

#### 地图服务控制台配 IP 白名单
- 登录 https://console.tianditu.gov.cn/
- 我的应用 → 编辑 key → IP 白名单 → 填**服务器出口公网 IP**
- 查 IP：`curl -s https://ipinfo.io/ip`（在服务器上执行）

### 白名单故障排查
| 现象 | 原因 | 解决 |
|------|------|------|
| 后端 503 "未配置 TIANDITU_KEY" | 后端没填 key | 配 .env 重启 |
| 地图服务 403 "IP不匹配" | IP 白名单没填/填错 | 重新查出口 IP 填入 |
| 换电脑后灰屏 | IP 变了白名单未更新 | 改用高德(见三节) |

## 四、L2 离线影像 MBTiles（桌面版按需导入）

桌面打包版（exe/dmg）要卫星影像时的**唯一可行方案**：用脚本下载指定区域影像打包成 MBTiles，放入应用目录，后端自动优先读取。

### 下载脚本
```bash
# 方式1: 按行政区(从 geo_index 反查 bbox)
backend/.venv/bin/python scripts/download_tianditu_mbtiles.py \
    --key 你的地图服务key \
    --adcode 532501 \
    --zoom-max 10 \
    --out data/geo/tiles/gejiu_img.mbtiles

# 方式2: 按经纬度范围
backend/.venv/bin/python scripts/download_tianditu_mbtiles.py \
    --key 你的key \
    --bbox 102.8,22.9,103.5,23.7 \
    --zoom-min 5 --zoom-max 10 \
    --out data/geo/tiles/gejiu_img.mbtiles
```

### 参数选择建议
| 缩放级别 | 清晰度 | 单区域体积 | 适用 |
|----------|--------|-----------|------|
| 8 级 | 省会级 | 几十MB | 概览 |
| **10 级** | 街道级 | 几百MB | **推荐** |
| 12 级 | 场地周边 | 1-3GB | 精细 |
| 14 级 | 村级 | 数GB-数十GB | 不推荐(太大) |

### 导入桌面版
下载完成后，`data/geo/tiles/*.mbtiles` 会随打包脚本一起进 exe（见下节）。运行时后端 `/map/tile` 自动优先读 MBTiles，无则走在线。

### 下载脚本的关键点
- **断点续传**：中断后重跑会跳过已下载瓦片。
- **礼貌限速**：默认 0.1s/瓦片，避免触发地图服务限流。
- **体积预估**：运行前会预估瓦片数和体积，>5万会二次确认。
- **合规**：瓦片仅供本项目离线使用，不得再分发；请确认 key 授权范围。

## 五、打包配置（桌面版 exe/dmg）

`packaging/srs.spec` 已配置：
- `data/geo/`（L1 行政区，27MB）**自动随 exe 打包**。
- `data/geo/tiles/*.mbtiles`（L2 影像，若存在）自动打包；不存在则跳过。
- `matplotlib` 已加入 hidden_imports（报告图件依赖）。

```bash
# 打包
backend/.venv/bin/pyinstaller packaging/srs.spec --clean
# 输出 dist/SRS.app 或 dist/SRS/
```

打包后的 exe：
- **默认开箱即用**：L1 离线行政区底图 + 采样点 + 报告图件，零配置零外网。
- **可选升级**：用户把 `*.mbtiles` 放入应用数据目录的 `data/geo/tiles/` 即启用 L2 离线影像。

## 八、故障排查

### 地图灰屏
1. 检查后端 `/map/geo/index` 是否返回 35 省/475 地市/2728 县 → 数据未安装则跑下载脚本。
2. 检查浏览器控制台是否有 `/map/geo/boundaries` 404 → adcode 错或数据缺失。
3. L1 离线底图不依赖外网，灰屏通常是 JS 错误，看 console。

### 报告无图
1. 检查 `report_service.py` 的 `map_image` 是否非空。
2. venv 是否装了 `matplotlib`（`pip install matplotlib`）。
3. 采样点是否缺经纬度（无坐标则回退文字）。

### MBTiles 不生效
1. 文件命名必须是 `*_img.mbtiles`（影像）或 `*_vec.mbtiles`（矢量）。
2. 必须放在 `data/geo/tiles/` 目录。
3. 打包版要重新 `pyinstaller` 才能纳入。
