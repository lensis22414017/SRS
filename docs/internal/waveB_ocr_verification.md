# Wave B OCR 交叉验证报告 — 三模型实证不可行

> 生成：2026-06-26 | 模式：EXECUTE（项目组授权 Wave B OCR）| 证据：三多模态模型 OCR 实测 + sanity ground-truth
> 结论：**多模态 OCR 对 GB36600 扫描表不可靠（三模型三种失败），维持生态库 OP 权威源**

## Executive Summary

按项目组授权验证 Wave B OCR。**诚实纠偏**：读原 memory 发现 2026-06-25 已关键修正——**矢量PDF（有文本层）多模态识别可信，扫描PDF（0文本层）才幻觉**。GB36600 正文表页是矢量，有机阈值已于 2026-06-25 用 4.5v analyze_image 矢量识别 + 项目组核对**入库**（`load_standard_thresholds._GB36600_ORGANIC` 84行），生态库 OP 63 种即基于此。

本轮 gemma 测试走的是 **PyMuPDF 渲染图路径**（降级为扫描 OCR），三模型全失败（接口/值幻觉）——这**佐证** memory 判别"渲染图路径幻觉，矢量路径可信"，**不是否定** Wave B（Wave B 实质已由 2026-06-25 矢量识别完成）。结论：GB36600 有机阈值已权威入库，**无需 gemma 渲染图 OCR 重做**。

## 二、值幻觉铁证（gemma-26b 萘）

| 因子 | gemma-26b 提取 | ground-truth（生态库，项目组核对原文） | 判定 |
|---|---|---|---|
| 萘 | 一类=490 / 二类=12900 | 一类=**25** / 二类=**70**（生态库:151） | ✗ 幻觉（490实为䓛值，张冠李戴） |
| 石油烃(C10-C40) | 未提取 | 一类=826 / 二类=4500 | ✗ 漏提 |

gemma-26b 把**䓛的一类值 490 错配给萘**，二类 12900 无对应——典型 LLM 幻觉（值臆造+因子错配），非 OCR 误差。

## 三、为什么 OCR 交叉验证无价值

1. **生态库 OP 已是权威源**：63 种有机物（生态障碍因子集.xlsx 补全 + PCB 科学计数法修复 + 项目组核对原文标"high"confidence）
2. **GB36600 权威CSV 仅 16 种**（OCR 废弃后人工核对版）——比生态库少
3. **OCR 三模型不可靠**：接口问题/值幻觉/全页幻觉，交叉验证两个不可靠源无意义
4. **memory 教训**（2026-06-23）：确定性公开数据用权威文本+人工核对，不靠 LLM OCR

## 四、结论与处置

**Wave B OCR 不可行，维持生态库 OP 权威源。**

- 生态库 `data/knowledge_base/阈值库/生态/thresholds.csv`：221 行（HM 10+ + OP 70 一类/二类双值 + 理化肥力），PCB 已修，是双轨诊断生态轨的权威阈值源
- 生产库 `data/knowledge_base/阈值库/生产/thresholds.csv`：161 行（HM 8 GB15618四段 + OP 63 GB36600一类 + 理化肥力）
- 双轨诊断已打通（生产0.6471/生态0.5596 实证），阈值来自这两库，非 OCR
