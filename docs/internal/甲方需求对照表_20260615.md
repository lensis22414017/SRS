### 检查点 2：RAG 是否真的可用？

**结论：真实可用，已验证。** 实测四维度：

| 维度 | 方法 | 结果 |
|---|---|---|
| **关键词检索** | 查"砷修复" | ✅ 命中砷因子 + 8 阈值 + 8 技术（带来源） |
| **同义词容错** | 查"Pb" | ✅ 精确命中铅因子+铅阈值（中英符号互查） |
| **无关词不乱答** | 查"今天天气" | ✅ 0 命中（符合"不伪造"） |
| **模型降级** | 模型乱码/不可达 | ✅ 自动降级为结构化知识库答案 |

**RAG 实质**：关键词 SQL 检索 + Python 子串打分（无向量库），对结构化阈值/因子/技术库查询足够，证据可追溯。本轮补同义词映射（砷↔As、铅↔Pb、PAH/TPH/BTEX 等 + 错字砐→砷）。

## 六、残留风险（如实标注，不回避）

1. **模型 AUC≈1.0**：阈值派生虚高风险，须持续标注，不可包装成真实泛化性能。
2. **地图服务底图**：L1 离线行政区不依赖；L2 在线仅服务器固定 IP 场景（白名单）。
3. **前端主包 2.5MB**：后续路由级懒加载。
4. **乡镇级地图**：无免费开放数据源，县级为离线极限（匹配业务粒度）。
5. **RAG 架构**：关键词检索，无向量语义召回（同义词已容错）。
6. **`.app` 打包**：onefile 不稳，已加首启自检过渡。
