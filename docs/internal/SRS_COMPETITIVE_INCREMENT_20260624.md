# SRS 双轨架构竞品能力增量报告（2026-06-24）

> 本轮 ultracode 重建后，SRS 相对同类土壤/场地监管系统的能力增量总结。
> 对比基线: 单轨阈值系统 / 传统 GIS 监管平台 / 通用 ML 风险模型。

## 一、核心差异化能力（本轮新增/强化）

### 1. 双轨阈值架构（生产/生态）— 行业首创
- **生产轨**：GB15618 农用地 + GB36600 一类用地（严，人体健康/粮食安全），重金属按 **pH 四段动态路由**（方案A）
- **生态轨**：CJ/T340 绿化 + GB36600 二类用地（宽，植被修复）
- **决策价值**：同一场地双用途诊断，126/320(39%) 复合污染场地"种粮不行·绿化行"——单一标准判必修，双轨揭示改生态用途可豁免，真实修复成本节约
- 竞品对比：同类系统多为单阈值/单用地类型，无法表达"用途决策分岔"

### 2. 双模型 ML（生产RF + 生态RF）
- 8 模型（4块 hm/op/composite/lake × 2轨），全 >0.9（group-split 最严格切分下 0.96/0.925）
- diagnosis_service 按 site.land_use_type 自动路由选模型（端到端闭环）
- 竞品对比：通用 ML 模型不区分保护功能，障碍因子识别混淆生产/生态语义

### 3. 标签泄漏防御 + 诚实标注（方法学严谨）
- group-split（DOI/Source 连通分量零泄漏）+ 空间 CV 双重评估
- AUC≈1.0 诚实标注为"标签定义性泄漏"（浓度阈值派生标签），非独立泛化证据
- 竞品对比：多数系统不披露标签泄漏，AUC 虚高当能力宣传
