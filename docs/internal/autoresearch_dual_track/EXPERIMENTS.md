## 特征组诊断 (2026-07-01)
| 特征组 | prod test AUC | 判读 |
|---|---|---|
| 理化(11) | 0.5329 | 接近随机, 无判别力 |
| GEE(14) | 0.6692 | 中等信号(环境因子) |
| 浓度列(455) | 0.5343 | valid 0.62但test崩=过拟合, 非派生浓度对泛化无贡献 |
| GEE+浓度(469) | 0.6861 | 浓度叠加GEE略有提升 |
| 全特征(480) | 0.6850 | ≈GEE+浓度 |

核心结论: 非派生浓度列(Fe/Mn/PAH单体等, 非空率最高4.5%)对"是否超标"标签泛化无判别力。
真正有信号的浓度列(8重金属, 非空25-56%)恰好是标签派生列(必须剔除)。
物理上限由GEE环境因子决定, test~0.68-0.70。这不是模型优化能突破的, 是特征判别力的本质上限。
