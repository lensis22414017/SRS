# SRS v1.1.0-rc.1（发布候选，非正式交付版）

污染场地土壤生态-生产功能重构监管系统（SRS）。本版本回应 2026-07-30 甲方意见（C1–C6）。
**本版本为预发布（prerelease）**：方法口径尚待课题组确认，课题三还没有真实的修复后数据，Windows 实机验收结果以本页"Windows 测试环境"一节为准。

## 主要变化

- **修复前 / 修复后数据分离（C4）**
  - 新增数据阶段、子课题、数据来源、方法版本字段（迁移 `0007`）。
  - 课题一、课题二只读取修复前数据。
  - 课题三修复后数据存入独立批次与记录表。
- **课题三修复后 SSUI 独立导入（C4）**
  - 使用 `SSUI-POST-v1.1` 模板。
  - 校验预览不入库，错误定位到"工作表 / 行 / 列"。
  - 事务性确认入库，计算后可导出 xlsx。
  - 权重按轨道取自方法 PPT（第 13 / 14 页），结果不截断到 1.0。
- **利用方向结论（C3）**
  - 生产门禁按 GB 15618-2018，生态门禁按 GB 36600-2018，再结合功能评分，输出五类结论。
  - 门禁结果不可被评分抵消；证据缺失一律判为"证据不足"。
  - 修复前只给情景判断和修复目标。
- **全流程追溯（C5）**
  - 进入页面即显示五阶段引导和模板下载，查看引导不创建记录。
  - 选择场地后显示真实进度（7 个里程碑）。
- **演示（C2）**
  - 固定种子生成的蒙特卡洛演示包，全程带"模拟数据——仅供测试/演示"标签。
  - 使用独立演示库。
- **文档（C6）**
  - 用户操作手册 v1.1.0（DOCX/PDF）。
  - 操作演示 PPT（公开版）。

## 升级

直接安装即可。首次启动时自动为旧库补充字段和新表：只新增，不删除、不修改已有数据，旧数据视为修复前数据。升级前建议先备份。
