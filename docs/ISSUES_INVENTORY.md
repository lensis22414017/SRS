# SRS 系统潜在问题深度盘点（截至 v1.0.0 打包前）

> 裴总要求"深度盘点可能还有哪些问题"。本清单按严重度分级，含已发现但未修、运行时可能暴露、打包后可能出现的全部风险点。

---

## 🔴 P0 — 影响核心可信性（甲方可能发现并质疑）

### 1. KOS 稳定性分量 S=0.8 硬编码（已在 AUDIT_FOR_GPT.md 详述）
- **影响**：所有因子 S 项恒定 0.16，KOS 排名实际只由 W（用途权重）决定
- **当前**：4 个超标因子 KOS 差异仅来自 W（0.175~0.213），区分度极低
- **修复**：需重复样数据计算动态 S，当前无数据支撑，标注为已知限制

### 2. 17/18 场地无诊断结果（已在 AUDIT_FOR_GPT.md 详述）
- **影响**：除个旧外，系统从未在真实场地验证过 KOS 完整链路
- **修复**：打包后建议用演示数据跑一遍全链路，或向甲方说明"需先运行诊断才有结果"

### 3. As=12420 mg/kg 数据异常（已在 AUDIT_FOR_GPT.md 详述）
- **影响**：砷超标 310 倍，疑单位错误（μg/kg vs mg/kg）
- **验证**：需裴总确认个旧原始 Excel 的砷单位

### 4. 因子命名空间三套断裂（已在 AUDIT_FOR_GPT.md 详述）
- **影响**：VALUE_TO_FEATURE 映射表不完备时，因子被当"未知有机物"
- **风险**：甲方导入自有数据时，因子名变体（如"Cd(mg/kg)"）可能匹配失败

## 🟡 P1 — 功能性缺陷（影响使用体验）

### 5. weasyprint 不可用 → PDF 降级到 xhtml2pdf
- **影响**：PDF 格式不如 weasyprint 完美（实测基本可用，但复杂 CSS 可能丢）
- **现状**：缺 GTK 系统库（libgobject/pango/cairo），Windows 常见问题
- **修复**：打包时静态捆绑 GTK（复杂），或接受 xhtml2pdf 降级（当前策略）

### 6. Redis 不可用 → 缓存降级
- **影响**：地图 GeoJSON/边界数据无缓存，每次请求重新读文件
- **现状**：已有前端内存缓存（Map() 对象），影响不大
- **修复**：打包可不含 redis，标注"可选组件"

### 7. OP（有机污染）模型为探索性
- **影响**：`model_registry_v0.8.json` 中 op/hm_op 模型 status=exploratory
- **现状**：前端会显示"探索性模型"标签
- **修复**：文档说明 OP 模型仅供参考，建议结合规则筛查

### 8. 模拟数据未预置到 DB
- **影响**：甲方首启系统是空的，需手动导入 18 份 Excel 才能看到数据
- **裴总决策**：模拟数据作为 Excel 单独提供（已确认）
- **缓解**：USER_GUIDE 有导入步骤说明

### 9. 数据库种子只有组织/角色/用户/权限，无场地/因子字典/阈值
- **影响**：首次启动 DB 是空的，场地列表为空
- **现状**：阈值表(131条)和技术库(10条)会在首次 import 时加载
- **风险**：如果甲方不导入数据就点诊断，会报"无检测数据"

## 🟢 P2 — 打包/运行时风险（可能影响安装）

### 10. PyInstaller 打包体积大（~350MB+）
- **原因**：sklearn/scipy/pandas/shap/matplotlib 全量打包
- **影响**：安装包大，下载/传输慢
- **缓解**：Inno Setup 用 lzma2/ultra64 压缩（实测压缩到 ~120MB）

### 11. 首次启动慢（~10-15秒）
- **原因**：create_all 建表 + seed_if_empty 加载种子 + pywebview 初始化
- **现状**：launcher 有环境自检输出，用户能看到进度
- **缓解**：USER_GUIDE 说明"首次启动请等待 10-15 秒"

### 12. 端口 8000 冲突
- **原因**：其他程序占用 8000 端口
- **现状**：launcher 自检会报 fail，用户需手动改端口
- **风险**：甲方电脑如有其他服务用 8000，会启动失败
- **缓解**：launcher 支持 --port 参数，USER_GUIDE 有说明

### 13. 杀毒软件误报
- **原因**：PyInstaller 打包的 exe 常被杀软误报（尤其国产杀软）
- **影响**：甲方可能无法运行
- **缓解**：需数字签名（成本高），或文档说明"添加白名单"

### 14. AppData 权限问题
- **原因**：某些企业环境限制 AppData 写入
- **影响**：数据库/上传文件无法创建
- **缓解**：launcher 自检会报 fail，但用户可能不知道怎么解决

### 15. 多用户冲突
- **原因**：SQLite 不支持并发写，多个 SRS 实例同时运行会锁库
- **影响**：同一台电脑开两个 SRS 窗口会报错
- **缓解**：launcher 有端口检测+单实例逻辑
