## 三、固定演示路线(12 步)

1. **登录系统**(admin / Demo@2026)
2. **数据概览**(看场地数量、地图、统计卡片)
3. **场地管理**(展示 3 个真实场地)
4. **进入云南个旧**(场地详情,134 采样点地图)
5. **障碍因子分析 → 运行生产用途诊断(KOS)**
6. **展示关键障碍 Top-5**(Pb>Cu>As>Zn,KOS 评分进度条)
7. **切换生态用途诊断**(展示两轨差异:As 排序上升)
8. **查看模型贡献度**(横向图,不写"SHAP")
9. **查看建议补测**(7 项未实测因子)
10. **查看数据质量提示**(9 个完全未知物质 → 诚实标记)
11. **功能重构分析**(限制因子含 KOS Top:Zn/Cu/Pb/As)
12. **方案推荐**(5 技术卡片:植物修复/农艺调控/固化/客土/淋洗,匹配 0.87-0.955)

## 四、甲方话术(演示用语)

> "系统采用规则诊断与模型解释结合。规则层负责判断是否构成障碍,模型层负责辅助识别对当前用途障碍指数贡献较大的因子,最终通过关键障碍综合评分输出排序。未检测但重要的指标不会被系统伪装成结论,而是列为补测建议。"
