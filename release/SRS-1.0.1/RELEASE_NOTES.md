## 安装方法

1. 双击 `installer/SRS-Setup-1.0.1-Windows-x64.exe`
2. 按安装向导操作（选择目录 → 创建桌面快捷方式）
3. 安装完成后双击桌面「污染场地监管系统」图标启动
4. 首次启动请等待 10-15 秒（自动初始化数据库）
5. 默认账户: `admin` / `Demo@2026`（首次登录后请修改密码）

## 演示数据

`samples/demo_data/` 含 18 份模拟场地数据 Excel（覆盖重金属/有机/复合×轻度/中度/重度×12省）。
通过系统「数据导入」功能导入即可演示全部功能。

## 方法学诚实声明

1. **KOS 是规则门控、用途权重与模型贡献形成的辅助排序**，非纯数据驱动。
2. **模型全局贡献不代表局部因果关系**，SHAP 贡献份额仅辅助参考。
3. **S（稳定性分量）当前为固定透明化参数**（0.8），无重复样数据支撑动态化。
4. **OP（有机污染）轨道属于探索性辅助结果**，建议结合规则筛查和人工复核。
5. **已完成 3 个原始场地工程回归验证**（个旧/栖霞/农村），不是大规模外部科学验证。
6. **正式超标结论仅适用于身份、单位兼容且阈值适用的因子**。动态阈值从 GB15618/GB36600 数据库按 pH 和土地用途查询。
7. **未收录因子通过模型候选、规则型族群归类和未知因子保留机制处理**，不丢弃任何实测数据。
8. **AI 文本仅为润色**，经事实校验（19 禁止词+因子-值-单位-排名绑定），失败时回退确定性结论。
9. **AI 大模型（智谱 GLM-5.2）和高德地图 key 已预配**，甲方开箱即用。
