# 污染场地土壤障碍因子诊断系统（KOS）— 费曼学习法详解

## 一、这个系统要解决什么问题？

一块被污染的土地，到底能不能安全地种植农作物（生产用地）或者建成公园（生态用地）？这取决于土壤中有什么污染物、浓度有多高、超没超过国家规定的安全标准。

KOS（Key Obstacle Scoring，关键障碍因子评分）系统就是做这件事的：从几十上百个检测指标中，自动找出最需要关注的 10 个"障碍因子"，并告诉你它们有多严重。

## 二、KOS 是怎么一步步诊断的？

### 第 1 步：因子识别与规范化
你上传的 Excel 文件中可能有这些列名：镉_Cd(mg/kg)、铅_Pb（mgkg）、有机质(%)。系统首先要"认"出这些是什么——这叫因子规范化。

怎么认的？
1. 去括号、全角转半角、统一大小写 → "镉_cd(mg/kg)" → "镉cd(mg/kg)"
2. 查别名表（factor_aliases_v0.8.yaml）："镉" → canonical code "Cd_mgkg"
3. 如果别名表没有，用关键词模糊匹配（如含"镉"或"Cd"就归为 Cd_mgkg）
4. 单位转换：如果列名里写的单位是 mg/kg 但模型需要的单位是 ng/g，自动 ×1000

### 第 2 步：阈值解析（判断是否超标）
系统数据库里存了两套国标：
- GB 15618-2018 农用地土壤污染风险筛选值 → 用于生产轨
- GB 36600-2018 建设用地土壤污染风险筛选值 → 用于生态轨

对于每个因子，系统根据场地的 pH 值和用地类型，自动选择对应的标准值：
- 比如场地 pH=6.86，镉的 GB15618 阈值就选"6.5<pH≤7.5"档的"其他用地"值
- 如果国标里没找到（比如养分指标、理化指标），系统会用文献/行业标准兜底（NY/T 1749、CJ/T 340、全国二普等）

### 第 3 步：KOS 五维综合评分
这是 KOS 系统的核心。每个因子的最终评分 KOS 由五个维度加权合成：

```
KOS = B × (0.30×R + 0.25×W + 0.15×M + 0.20×S + 0.10×E)
```

**B（规则门槛）= 0 或 1**
这是"一票否决"门槛：只有同时满足两个条件，B 才等于 1：
1. 该因子有明确的阈值（国标或行标）
2. 该因子被实测了（有检测数据）
B=0 的因子直接淘汰，不进 Top-N。

**R（规则严重度）= 0~1**
衡量超标有多严重。数学公式：R = min(1, log(1+实测值/阈值) / log(11))
- 比如镉实测值 1.2 mg/kg，阈值 0.3 mg/kg，超标 4 倍 → R≈0.85
- 超标 10 倍时 R≈1（封顶）
- 不超标时 R=0

**W（用途权重）= 0~1**
不同污染物在生产和生态用地的"重要性"不同：
- 镉：生产轨 W=0.9（农用地对镉极敏感），生态轨 W=0.5（建设用地宽容度高）
- 有机质：生产轨 W=0.3（不是主要障碍），生态轨 W=0.6（绿化土壤需要有机质）

**M（模型贡献度）= 0~1**
来自随机森林（RandomForest）模型的 SHAP 值。SHAP 衡量了每个因子对模型预测的"贡献大小"。
- 贡献大 = 该因子在训练数据中对障碍指数的影响大
- M 只占 15%，是辅助参考，不是主导

**S（稳定性）= 0~1**
衡量该因子在不同采样点、不同模型版本下排名是否一致。如果每个点都超标，S 就高；如果只有一个点偶然超标，S 就低。

**E（证据等级）= 0~1**
- A 级（1.0）= 有国标实测值
- B 级（0.8）= 有行标/文献阈值
- C 级（0.5）= 仅有模型推断

### 第 4 步：局部 SHAP 解释
不只是给一个全局排名，系统还会选出一个"最不利采样点"，用 SHAP 库对这个点做局部解释——告诉你在这个特定采样点上，哪些因子的实际影响最大。这种"逐点解释"比"平均值"更真实。

### 第 5 步：输出三层结果
1. **关键障碍因子 Top-N**（法规超标层）：有国标阈值、实测超标 → 正式结论
2. **模型候选障碍**（辅助识别层）：模型认识但无适用阈值 → 专家复核
3. **族群级预警**（开放集层）：未知物质按族群归类 → 建议补测

## 三、生产轨 vs 生态轨的区别

生产轨（农用地）：用 GB15618 阈值，重金属（Cd/Pb/As 等）权重高，阈值严
生态轨（建设用地/绿地）：用 GB36600 阈值，有机物（PAHs/PCBs）和养分指标权重更高

同一块地，选不同轨会得到不同的 Top-N 排名——这体现了"修复后用途决定修复标准"的设计思想。

## 四、模型是怎么训练的？

系统内置了 4 个随机森林模型：
- all_prod：所有场地，生产轨
- all_eco：所有场地，生态轨
- hm_prod：仅重金属场地，生产轨
- op_prod：仅有机污染场地，生产轨

每个模型用 110 个特征（重金属浓度 + 理化性质 + GEE 卫星协变量 + 缺失指示器）预测障碍指数 OI（Obstacle Index），训练数据来源于全国 41,000+ 个土壤样点。

SHAP 全局解释从约 110 个特征中筛选出 36 个"实测贡献因子"（过滤掉缺失指示器和 GEE 代理），作为 M（模型贡献度）的计算依据。

## 五、用户关心的常见问题

**Q: 为什么有些因子模型贡献度(M)为 0？**
A: 因为这些因子（如全磷、碱解氮）在模型训练时没有被纳入特征列，所以 SHAP 无法计算它们的贡献。但它们的 R（超标严重度）和 W（用途权重）仍然有效，KOS 评分主要靠这两项（共占 55%）。

**Q: 为什么生态轨的障碍因子总比生产轨少？**
A: 因为 GB36600 建设用地阈值远高于 GB15618 农用地阈值。铜：生产轨 50-200 mg/kg，生态轨 2000-18000 mg/kg——差了 10-100 倍。

**Q: 阈值"待核实"是什么意思？**
A: 当系统用文献/行业标准兜底（非国标）时，会标记为待核实。这是诚实声明，告诉用户：这个阈值可以参考但不是国标，建议人工确认。

**Q: 多久应该重新诊断一次？**
A: 每次新检测数据导入后、或修复工程完成后，都建议重新运行诊断，追踪障碍因子的变化趋势。
