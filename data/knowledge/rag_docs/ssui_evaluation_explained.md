# SSUI 土壤可持续利用评价 — 用户操作指南与原理详解

## 一、SSUI 是什么

SSUI（Soil Sustainable Utilization Index，土壤可持续利用指数）回答一个问题：**这块场地修复后，能否长期持续地用于生产（或生态）用途？**

与功能重构分析（评估"能不能用"）不同，SSUI 评估的是"用起来能否持续"——不仅要土壤安全，还要经济上可行。它综合考虑了土壤安全性、经济成本和经济效益三个维度。

SSUI 指数范围 0-1，划分为四个等级：
- **≥ 0.80**：高度可持续（土壤安全、经济可行）
- **0.60 ~ 0.80**：中度可持续（基本可用，存在一定风险）
- **0.40 ~ 0.60**：低度可持续（勉强可用，需重点关注）
- **< 0.40**：不可持续（存在严重安全隐患或经济不可行）

## 二、如何使用 SSUI 评价

### 操作步骤

1. 在左侧导航栏点击「SSUI评价」
2. 从下拉列表选择一个已导入的场地
3. 设置评价参数：
   - **利用年限（t）**：场地修复后计划使用的年数，默认 2 年。时间越长，SSUI 越高（f(t) = 1 + 0.03×t）
   - **管理强度**：低/中/高，反映后期管护投入水平。强度越高，管理调节因子 M 越大
   - **评价年份**：选择经济数据的参考年份，默认自动
   - **数据场景**：生产/生态
   - **评价用途**：生产/生态
4. 勾选「使用全国平均经济数据」复选框（如果场地没有真实经营数据）
5. 点击「运行评价」
6. 查看 SSUI 指数、等级和详细得分

### 经济数据管理

如果场地有真实经营数据（合同、发票、账本等），点击「经济数据」按钮可录入或导入 Excel：

- 支持按年份录入 D18-D25 共 8 项经济指标
- 可下载 Excel 模板批量填写后导入
- 数据来源分为：场地真实数据（site_actual，正式评价）和全国平均参照数据（official_national_reference，参考评价）
- 系统已预填 2015-2024 年全国平均数据，甲方可直接使用

## 三、SSUI 的指标体系（D1-D25）

SSUI 采用 4 层指标体系：

```
目标层 A：土壤持续利用
  ├─ 准则层 B1：安全性（权重 50%）
  │    ├─ 指标层 C1：限制因子（D1-D15，15项土壤基础指标）
  │    └─ 指标层 C2：风险因子（D16 重金属 + D17 有机物，2项）
  └─ 准则层 B2：经济性（权重 50%）
       ├─ 指标层 C3：经济成本（D18-D21，4项成本指标）
       └─ 指标层 C4：经济效益（D22-D25，4项收益指标）
```

### D1-D15 限制因子（土壤基础性质）

| D码 | 名称 | 检测指标 | 参照来源 |
|-----|------|----------|----------|
| D1 | 土壤含盐量 | 电导率、含盐量 | TD/T1036-2013 |
| D2 | 土壤碱化度 | 碱化度、交换性钠 | CJ/T340-2016 |
| D3 | 土壤机械组成 | 砂粒/粉粒/黏粒/容重 | USDA + 全国二普 |
| D4 | 土壤含水率 | 含水率 | USDA 田间持水量 |
| D5 | 阳离子交换量 | CEC | 全国二普 + CJ/T340 |
| D6 | 盐基饱和度 | 盐基饱和度 | 全国二普 |
| D7 | pH | pH | TD/T1036 + CJ/T340 |
| D8 | 土壤有机质 | 有机质、SOC | 全国二普 6级 |
| D9 | 水稳性团聚体 | 水稳性团聚体 | 文献(中科院) |
| D10 | 有效态微量元素 | 有效Zn/Fe/Mn/B/Ca | CJ/T340-2016 |

### D16-D17 风险因子

- **D16 重金属**：镉、汞、砷、铅、铬、铜、镍、锌，采用 GB15618-2018 标准按 pH 分档匹配阈值

## 四、SSUI 计算方法

### 核心公式

```
SSUI = (B1 × 0.5 + B2 × 0.5) × f(t) × M
```

- **B1（安全性得分）** = C1限制因子 × 权重 + C2风险因子 × 权重
- **B2（经济性得分）** = C3经济成本 × 权重 + C4经济效益 × 权重
- **f(t) = 1 + 0.03 × t**：时间修正函数，t 为利用年限，反映修复效果逐年改善
- **M**：管理调节因子，取决于管理强度

| 管理强度 | 生产利用 M | 生态利用 M |
|----------|-----------|-----------|
| 低强度 | 1.10 | 1.05 |
| 中等强度 | 1.15 | 1.075 |
| 高强度 | 1.20 | 1.10 |

### D1-D15 归一化方法

每个指标先用外部参照范围做归一化（实测值转换到 0-1 区间）：
- **正向指标**（越高越好，如 CEC、有机质）：得分 = (实测值 - 下限) / (上限 - 下限)
- **负向指标**（越高越差，如含盐量）：得分 = 1 - (实测值 - 下限) / (上限 - 下限)
- **复合指标**（如 D10 含5种微量元素、D11 含3种养分）：各分项分别归一化后取均值

### D16-D17 风险评分

污染物的风险评分采用最严重超标因子决定原则：
- 对每个污染物计算 r = 实测最大值 / 标准阈值
- r ≤ 1（未超标）→ 得分 = 1.0
- r > 1（超标）→ 得分 = max(0, 1 - 0.5×(r - 1))
- 例如超标 2 倍 → 得分 = 0.5，超标 3 倍 → 得分 = 0

**法规单因子否决门禁**：如果任一污染物超标 ≥ 1 倍，最终等级不得评定为"可持续"。

## 五、评价结果的类型

### 正式评价
条件：D1-D15 全部 15 项实测齐全 + D16/D17 有法规阈值 + D18-D25 有场地真实经营数据
标签：绿色"正式评价"

### 参考评价
条件：使用全国平均经济数据（非场地真实数据），或 D1-D15 只有 6-14 项实测
标签：橙色"参考评价"，结论仅供参考

### 数据不足（Blocked）
条件：D1-D15 少于 6 项实测，或 D16/D17 完全无阈值可参考
标签：红色"数据不足"，无法生成 SSUI

## 六、结果页面的图表说明

### 仪表盘
显示 SSUI 指数（0-1），指针位置直观反映可持续性等级。

### D1-D25 元指标得分表
列出每个元指标的归一化得分和权重。得分越接近 1 越好，越接近 0 越差。

### 双轴条形图
同时展示各指标的归一化得分（蓝色柱）和权重（红色柱），一眼识别"权重高、得分低"的关键管控对象。

### 安全性-经济性二维象限
散点图展示场地在安全性和经济性两个维度上的位置。"双优区"（右上）表示两个维度都很好，"双弱区"（左下）表示都需要重点修复。

### C1-C4 准则层得分对比
四个准则层（限制因子、风险因子、经济成本、经济效益）的得分柱状图，快速定位最薄弱的环节。

### 计算过程追溯
完整展示从原始数据到最终 SSUI 的每一步计算，包括各层得分、权重、修正系数等，方便审计和复核。

## 七、常见问题

**Q: 为什么 SSUI 一直是 blocked？**
A: 最常见的原因是：(1) 没有经济数据——需要点击「经济数据」录入或勾选使用全国平均数据；(2) 污染物阈值未解析——阈值库中没有该污染物的标准限值，需要补充。

**Q: "参考评价"和"正式评价"有什么区别？**
A: 参考评价使用了全国平均经济数据（不是场地的真实经营数据），结论仅作初步参考。正式评价需要有场地的真实合同/发票/账本数据，可作为决策依据。

**Q: C1 部分覆盖是什么意思？**
A: D1-D15 共 15 项土壤基础指标中，场地只实测了其中一部分（如 6-8 项），其余指标（如碱化度、微量元素、酶活性等）没有检测数据。系统会用已有指标做参考评价。

**Q: f(t) 和管理强度 M 怎么设置？**
A: f(t) 中的 t 是场地修复后预期的使用年限，默认为 2 年。M 是管理强度，反映后期的管护投入水平——如果计划精细化管理（精准施肥、全周期监测），选"高强度"；普通管理选"中等"。

**Q: 经济数据从哪里来？**
A: 系统已预填了 2015-2024 年全国平均参照数据（来源于全国农产品成本收益资料汇编和国家统计局）。甲方可直接使用这些数据做参考评价，也可替换为场地的真实数据。

## 八、数据来源与科学依据

### 经济数据
- 全国农产品成本收益资料汇编（2015-2022年）
- 国家统计局年度统计公报（2023-2024年人均可支配收入、稻谷单产）

### 安全参照范围
- 全国第二次土壤普查养分分级标准（有机质、氮磷钾、CEC等）
- CJ/T 340-2016《绿化种植土壤》（微量元素、渗透率、容重等）
- TD/T 1036-2013《土地复垦质量控制标准》（pH、含盐量、有效土层等）
- USDA Soil Survey Manual（含水率、盐渍化分级等）

### 污染物阈值
- GB 15618-2018《土壤环境质量 农用地土壤污染风险管控标准》
- GB 36600-2018《土壤环境质量 建设用地土壤污染风险管控标准》
- EPA RSL 2024（多溴联苯醚、全氟化合物等国内暂无标准的污染物）
