# 污染场地功能重构可行性分析 — 用户操作指南与原理详解

## 一、功能重构分析是什么

功能重构分析回答一个问题：**这块污染场地修复后，能不能用于农业生产（或生态建设）？**

系统从土壤质量、修复潜力、地形气候、灌排条件、碳库变化等多个维度，对场地进行综合评分。评分 >50 分即为"可行"，≤50 分为"不可行"。

分析分为两条轨道：
- **生产功能**：评估能否恢复为农田，种植水稻等粮食作物（28项指标）
- **生态功能**：评估能否恢复为绿地、公园等生态用地（25项指标，污染指标合并为1个）

---

## 二、如何使用功能重构分析

### 操作步骤

1. 在左侧导航栏点击「功能重构分析」
2. 从下拉列表中选择一个已导入的场地
3. 点击「运行评价」按钮
4. 系统自动并行计算生产轨和生态轨的结果
5. 查看综合得分、评价等级和关键限制因子

### 结果解读

结果页面包含以下内容：

**综合得分与等级**
- 得分范围 0-100，50 分为可行阈值
- 得分 >50：绿色标签"可行"
- 得分 ≤50：红色标签"不可行"
- 关键限制因子：列出拖累得分最严重的指标（用橙色标签显示，名称已自动转换为中文）

**雷达图（各评价指标得分）**
- 展示每个评价维度的得分（0-100），一眼看出哪些方面是短板
- 雷达图面积越大，综合评价越好

**贡献度条形图**
- 按贡献分从高到低排列各指标
- 前 2 名用红色标注（主要限制因子），中间用蓝色，其余用深蓝色

**高级可视化（点击展开）**
- 指标贡献瀑布图：展示各指标对综合得分的累计贡献，识别主导因子
- 短板仪表盘：用仪表盘展示最低得分维度的具体分值

**计算过程追溯**
- 按步骤展示完整计算过程，方便审计和复核

## 三、功能重构分析的计算方法

### 评分模型

采用**改进模糊综合评价法**：
```
综合得分 = Σ(F_i × T_i)
```
其中 F_i 是各指标的分等赋值（0-100），T_i 是指标权重。

### 生产功能评价指标（28项）

| 类别 | 权重 | 包含指标 |
|------|------|----------|
| 土壤质量类 | 15.26% | 镉、汞、砷、铅、铬、铜、镍、锌、六六六、滴滴涕、苯并[a]芘、pH |
| 修复潜力类 | 28.94% | 盐渍化程度、地下水埋深等 |
| 耕地质地 | 4.81% | 表层土壤质地 |
| 光温/气候潜力 | 8.42% | 光温生产潜力 |
| C库变化因子 | 0.81% | 耕地碳库变化 |
| 地形坡度 | 7.57% | 坡度等级 |
| 土壤有机碳 | 8.35% | 有机碳含量（可由有机质×0.58换算） |
| 灌排能力 | 11.19% | 灌溉排水条件 |
| 剖面构型 | 3.16% | 土壤剖面层次 |
| 有效土层厚度 | 4.60% | 有效土层厚度 |
| 全氮 | 2.22% | 土壤全氮含量 |
| 有效磷 | 1.17% | 有效磷含量 |
| 速效钾 | 1.06% | 速效钾含量 |
| 阳离子交换量 | 1.76% | CEC |
| 生物多样性 | 0.66% | 生物多样性指标 |

### 生态功能评价指标（25项）

包含 GB36600-2018 表1中45项和表2中40项污染物指标，以及 pH、含盐量、土壤质地、入渗率、CEC、养分、微量元素、有效土层等土壤基本性质指标。

### 评分规则

每个指标的得分根据评分规则文件 `ml/params/reconstruction_scoring_rules.json` 确定。评分方式包括：

- **阈值评分**：超标/达标二值判定
- **区间评分**：指标值在特定区间内得满分，区间外扣分
- **等级评分**：按分级标准（如全国二普养分分级）给分
- **覆盖率门禁**：生态轨评分指标覆盖率不足时，自动降级为类别级权重评估

### 等级判定

- 综合得分 >50 → "可行"
- 综合得分 ≤50 → "不可行"

## 四、常见问题

**Q: 为什么评分一直是"不可行"？**
A: 检查污染物是否超标。如果镉、汞、砷、铅等重金属超过 GB15618-2018 标准限值，污染物指标得分为 0，会大幅拉低综合评分。

**Q: "证据不足/无法评价"是什么意思？**
A: 场地提供的实测数据太少，无法覆盖足够的评价指标。生态轨要求至少覆盖 10% 的评价指标，生产轨要求更高。建议补充土壤检测数据。

**Q: 关键限制因子显示了哪些信息？**
A: 列出贡献分最低的指标，即最拖累综合评分的短板。例如"土壤有机碳含量得分为0，权重8.35%"表示有机碳严重不足。

**Q: 生产轨和生态轨的区别？**
A: 生产轨评价能否种地（农田），标准更严格，需评估肥力、灌排等农业条件。生态轨评价能否做绿地，标准相对宽松，更关注污染物是否达标。

**Q: 经济数据对重构分析有影响吗？**
A: 功能重构分析不涉及经济数据，仅评估土壤本身的生产/生态潜力。经济评价在 SSUI 模块中独立进行。

## 五、技术实现要点

### 有机质换算

如果场地只有"有机质"数据，系统会自动换算"土壤有机碳含量"：
```
土壤有机碳含量 = 有机质 × 0.58
```

### 污染物评分

- 每个污染物因子独立评分
- 有阈值时：与 GB15618/GB36600 标准限值比较，达标满分，超标扣分
- 无阈值时：该因子不参与评分
- 有机物评分采用降解率折算

### 覆盖率门禁

- 生态轨：覆盖率 ≥ 10%（COVERAGE_GATE_ECO = 0.10），否则无法评价
- 生产轨：覆盖率要求更高

### 类别级权重回退

当场地数据无法覆盖生态轨的全部 85+ 个 GB36600 指标时，系统自动执行类别级权重重新归一化，确保评价不因数据不足而完全失效。
