# SSUI 全量命中流程分析 — 上海_宝山区_复合污染_03

## 一、总体公式

```
SSUI = (B1安全 × 0.5 + B2经济 × 0.5) × f(t) × M
     = (SC1限制×0.3445 + SC2风险×0.2012 + SC3成本×0.2072 + SC4效益×0.2472) / 1.0 × 1.06 × 1.15
```

(t=2年, M=1.15中等生产强度)

## 三、计算流程

```
场地实测数据(37个因子)
    │
    ├→ [D1-D15 归一化] ← 安全参照CSV(ssui_safety_reference_v1.csv, 41个因子)
    │   ├ D1=0.35 → (0.35-0)/(4-0)=0.0875 (负向→1-0.0875=0.9125)
    │   ├ D3=39% → (39-0)/(100-0)=0.39 × weight
    │   ├ D5=12.0 → (12-5)/(25-5)=0.35
    │   ├ D7=6.86 → |6.86-6.5|/(9-4)=0.072 (pH区间归一化)
    │   ├ D8=1.16 → (1.16×10-6)/(40-6)=0.1647 (g/kg换算)
    │   └ D11 → N=(1.12-0.5)/(2-0.5)=0.413, P=(1.7-0.2)/(1-0.2)=1.0(clip), K=(179-30)/(200-30)=0.876
    │       avg=0.763 → × D11_weight
    │
    ├→ [D16/D17 风险评分] ← StandardThreshold表(15条有机物组阈值 + GB15618重金属)
    │   ├ D16: Cd r=0.95→无超标, score=1.0
    │   │     (r≤1→score=1.0; r=2→0.5; r=3→0.0)
    │   └ D17: PAHs r=3.66→超标, score=max(0,1-0.5×2.66)=0
    │       最严重超标: PAHs 2.01/0.55=3.66倍 → 触发法规单因子否决
    │
    ├→ [D18-D25 经济归一化] ← EconomicIndicator表(240条预填充)
    │   各指标用2015-2023年全国范围min/max归一化
    │   (min→0分, max→1分)
    │
    ├→ [组内加权聚合]
    │   SC1 = Σ(D1-D15得分×组内权重)/Σ权重 = C1得分
    │   SC2 = Σ(D16-D17得分×组内权重)/Σ权重 = C2得分 (D16+D17取最严重)
    │   SC3 = Σ(D18-D21得分×组内权重)/Σ权重
    │   SC4 = Σ(D22-D25得分×组内权重)/Σ权重
    │
    ├→ [准则层聚合]
    │   B1 = SC1×(0.3445/0.5457) + SC2×(0.2012/0.5457)
    │   B2 = SC3×(0.2072/0.4543) + SC4×(0.2472/0.4543)
    │
    └→ [SSUI]
        raw = (B1×0.5 + B2×0.5) × 1.06 × 1.15
        SSUI = max(0, min(raw, 1.0))
        
        结果: SSUI = 0.4706
        等级: 不可持续(法规超标3.66倍)
        标记: is_reference=True (C1仅6/15)
```
